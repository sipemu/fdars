# Quick 261126-3sq — ALN-BOX (GH #55)

## Goal
fdasrsf/fdasrvf-style elastic amplitude + phase boxplots with `classify` for new
functions, a `classify` for the existing MBD `phase_boxplot`, and elastic DP-means
clustering (`dpmeans_align`) with automatically learned K.

## Public API (additive)
- `alignment::elastic_boxplot`: `ElasticBoxplotConfig {alpha=0.05, k_a=1.0}`,
  `BoxplotRegion {Central50, CentralAlpha, WithinWhiskers, Outlier}`, `BoxplotSide {Q1,Q3}`,
  `BoxplotClassification`, `AmplitudeBoxplot` (+`classify_srsfs`), `ElasticPhaseBoxplot`
  (+`classify_warps`), `amplitude_boxplot_from_aligned`, `elastic_phase_boxplot`,
  `elastic_boxplots(data, argvals, lambda, cfg) -> ElasticBoxplots` (+`classify(new_data)`:
  aligns to the fitted median template, then classifies amplitude + phase).
- `PhaseBoxplot`: new `fence_lower`/`fence_upper` fields + `classify_warps`.
- `alignment::elastic_dpmeans(data, argvals, &DpMeansConfig) -> DpMeansResult`.

## Algorithm
Direct ports of fdasrsf 2.7.5 `boxplots.ampbox/phbox.construct_boxplot/classify`
(distance-to-median ordering, energy-based quartile pair, whisker distance,
`boxplot_region`) and `kmeans.dpmeans_align` (sequential DP-means pass, cluster
pruning, per-cluster SqrtMeanInverse normalisation, mean-SRSF templates,
k-means++ penalty heuristic seeded). Phase side uses fdasrsf's SqrtMedian
(Weiszfeld on the Hilbert sphere) with numpy-gradient / cumulative-trapezoid
numerics so golden values match.

## Validation
- Golden: fdasrsf 2.7.5 construct_boxplot/classify on fixed aligned inputs
  (mocked fdawarp — deterministic, bypasses DP), SqrtMedian; dpmeans_align
  labels/K on well-separated data with fixed λ.
- Invariants: r50 ≤ ralpha, training classification == fit, median = deepest
  (distance 0 / max depth), DP-means K=1 for huge λ, K=n for λ→0, K monotone in λ,
  objective formula.
