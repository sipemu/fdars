# Plan — ALN-EXPFAM (GH #60): exponential-family registration with generalized FPCA

## Goal
Port R `registr` 2.2.1 `register_fpca` (Wrobel et al. 2019 Biometrics; Wrobel & Bauer 2021 JOSS):
alternating (a) per-curve likelihood-based registration with monotone cubic B-spline
inverse warps (`registr`) and (b) variational-EM generalized FPCA (`fpca_gauss` /
`bfpca`) on the registered data, for gaussian / binomial / gamma / poisson families,
irregular (long-format) input and incomplete curves (`leading` / `trailing` / `full`
with endpoint penalty `lambda_inc`).

## Public API (new module `alignment/expfam_registration.rs` + helpers)
- `ExpFamily { Gaussian, Binomial, Gamma, Poisson }`, `CurveIncompleteness { Leading, Trailing, Full }`
- `RegisterFpcaConfig` (`#[non_exhaustive]`, Default = R defaults: Kt 8, Kh 4, npc 1,
  max_iterations 10, fpca_maxiter 50, fpca_seed 1988, fpca_error_thresh 1e-4, …)
- `register_fpca(data: &IrregFdata, config) -> RegisterFpcaResult` (+ `register_fpca_regular(FdMatrix, argvals, config)`)
- `registr_to_template(data, config)` (one `registr` pass against the GLM mean / `Y_template`)
- `gfpca_variational(data: &IrregFdata, family, npc, kt, …) -> GfpcaResult` (`fpca_gauss` / `bfpca`)

## Algorithm (mirrors registr source)
- Template basis: `bs(knots = quantile(t, seq(0,1,len=Kt-2))[-ends], intercept = TRUE)` on [t_min, t_max].
- Initial template: GLM (IRLS) of all data on that basis (log link for gamma/poisson).
- Warp: t̂ = Θ_h(t*) β, Θ_h cubic B-spline basis on the curve's own range with Kh−4 quantile
  inner knots; β monotone; endpoints fixed (complete) or free within [t_min, t_max]
  (incomplete) with penalty `n_i · λ_inc · pen` (R `loss_h`).
- Optimiser: R uses `constrOptim` (adaptive log-barrier + BFGS / Nelder–Mead). fdars uses an
  exact monotone reparameterisation (softmax increments, sigmoid endpoints) + in-crate L-BFGS
  with analytic gradients for all four families (deviation, documented).
- FPCA: variational EM exactly as `fpca_gauss_optimization` / `bfpca_optimization`
  (Jaakkola–Jordan bound); gamma/poisson use the gaussian FPCA with `*-varEM` loss (R default
  `fpca_type = "variationalEM"` behaviour).
- Outer loop: until mean((t̂_new − t̂_old)²/t_max²) ≤ 1e-4 or max_iterations, then final FPCA.

## Validation
- R registr 2.2.1 goldens (`golden_registr.R` → `register_fpca_golden.rs`), data from a portable
  LCG generated identically in R and Rust: template GLM coefs (tight), loss evaluated at R's β
  (tight), our initial-step loss ≤ R's, β close; fpca_gauss / bfpca with R's psi init (tight);
  full register_fpca warps / mean / FPC subspace within documented tolerance; incomplete
  leading/trailing/full; poisson / gamma initial-step losses.
- Invariants: finite-difference gradients (all families, all incompleteness modes), monotone
  warps, recovery of known warps on synthetic binomial / poisson data, λ_inc → ∞ pins endpoints,
  identity on unwarped data.
