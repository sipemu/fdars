# 261126-b83 — continuous_registration: honest converged flag + termination reason (GH #83)

**Goal:** `converged[i]` means the tolerance was met (or an exact stationary
point); report the stop reason per curve.

**Root cause:** `register_curve` set `converged = true` on `LmStep::Stalled`
(no damped step decreased the criterion), which also covered steps rejected by
`COEF_LIMIT`.

**Fix:** new `ContinuousRegistrationTermination { Converged, Stalled, CoefLimit,
MaxIter }` and `ContinuousRegistrationResult::termination` (serde default);
`LmStep` distinguishes `Stationary` (zero gradient → Converged) from
`Stalled { coef_limited }`; `damped_candidate` reports coefficient-limit
rejections. `converged = termination == Converged`. Fits/warps unchanged.

**Validation:** issue repro with `tol = 0`, `max_iter = 1000` → stalled curves
report `converged = false`, `n_iter < 1000`; default tol → Converged;
`max_iter = 1, tol = 0` → MaxIter.
