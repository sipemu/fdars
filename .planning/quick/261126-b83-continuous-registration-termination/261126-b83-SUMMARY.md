# 261126-b83 SUMMARY — continuous_registration converged flag (GH #83)

## Root cause
`register_curve` set `converged = true` on `LmStep::Stalled`, which covered
(a) an exactly zero gradient, (b) 40 failed damping increases (no decreasing
step resolvable), and (c) candidates rejected by `COEF_LIMIT` (indistinguishable
from Cholesky failures). So `converged` did not mean "tolerance met".

## Fix
- `ContinuousRegistrationTermination { Converged, Stalled, CoefLimit, MaxIter }`
  (`#[non_exhaustive]`, serde, re-exported from `alignment` and crate root) and
  `ContinuousRegistrationResult::termination` (`#[serde(default)]`).
- `LmStep::{Accepted, Stationary, Stalled { coef_limited }}`;
  `damped_candidate` returns `Candidate::{Admissible, Failed, CoefLimit}`.
- Termination: tol-met decrease or zero gradient → Converged; stall →
  Converged only if `f ≤ tol · f₀` (round-off floor of a zero-residual fit —
  needed because the relative-decrease test can never fire when f → 0; with
  `tol = 0` it needs f = 0), else CoefLimit/Stalled; loop exhaustion → MaxIter.
  `converged = (termination == Converged)`. No change to iterates.
- Deviation considered: treating every stall as non-converged broke
  `recovers_known_warps_both_criteria` (exact recovery, criterion < 1e-8 at a
  round-off stall) — that fit genuinely converged, hence the `f ≤ tol·f₀` rule
  rather than weakening the test.

## Tests (continuous_tests.rs)
- `stall_is_not_reported_as_converged` — issue repro, `tol = 0`,
  `max_iter = 1000`: n_iter < 1000, ≥ 1 curve Stalled, `converged` iff Converged.
- `termination_reason_converged_and_max_iter` — default tol → Converged;
  `tol = 0, max_iter = 1` → MaxIter / not converged.
- All existing golden R `register.fd` tests still pass (converged asserted).

## Gates
fmt; clippy all-targets (linalg,parallel,serde) clean; `alignment::continuous`
lib tests pass (default + --no-default-features linalg); alignment doctests
pass; rustdoc -Dwarnings clean; pmat 0.

## Behaviour change
`converged` flips to false for stalled/coef-limited curves; new `termination`
field. CoefLimit path has no dedicated test (no natural repro found within
the |c| ≤ 50 box); covered by code review only.
