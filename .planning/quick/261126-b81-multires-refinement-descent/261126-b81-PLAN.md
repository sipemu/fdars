# 261126-b81 — multires refinement never increases the objective, uses lambda (GH #81)

**Goal:** the gradient-refinement stage of `elastic_align_pair_multires` must be
a descent method on the penalised elastic objective, so it can never worsen the
coarse-DP warp, and `lambda` must enter it.

**Root cause:** `refine_gamma_step` took a fixed-size finite-difference
coordinate step `γⱼ ← γⱼ − step·∂d/∂γⱼ` without any descent check (the
single-point gradient is O(1/Δt) large, so steps overshoot and jag the warp),
and the objective ignored `config.lambda`.

**Fix:** objective `E(γ) = ‖q₁ − SRSF(f₂∘γ)‖² + λ Σ (Δγ/Δt − 1)² Δt` (the
squared reported distance + the DP's first-order penalty); each coordinate step
backtracks (halving up to 10×) and is accepted only if `E` strictly decreases;
the per-sweep `normalize_warp` is reverted if it raised `E`.

**Validation:** issue repro at m=101/400: refined distance ≤ coarse distance for
(10, 0.01), (40, 0.1), (5, 1.0); penalised objective non-increasing for λ>0;
λ=1e6 keeps the warp at least as close to identity as the coarse warp.
