# 261126-b81 SUMMARY — multires refinement descent + lambda (GH #81)

## Root cause
`refine_gamma_step` applied `γⱼ ← clamp(γⱼ − step·∂d/∂γⱼ)` with no check that
the objective decreased. Moving a single grid value changes the SRSF (a
derivative) by O(1/Δt), so the single-coordinate gradient is large and fixed
steps overshoot into jagged warps; more/larger steps made it worse. Not a sign
error. The objective was the plain distance, so `lambda` was ignored.

## Fix
- `refine_objective`: `E(γ) = d(q₁, SRSF(f₂∘γ))² + λ Σ (Δγ/Δt − 1)² Δt`
  (squared reported distance + the DP's first-order `l2gam` penalty).
- `refine_gamma_step`: FD gradient of `E`, clamped step, backtracking (≤ 10
  halvings), accept only if `E` strictly decreases.
- `refine_gamma`: tracks `E`; reverts the per-sweep `normalize_warp` if it would
  raise `E`. Result: `E` is non-increasing ⇒ final distance ≤ coarse distance
  for `lambda = 0`.

## Tests (multires.rs)
- `multires_refinement_never_increases_distance` — issue repro at m = 101/400,
  (10, 0.01), (40, 0.1), (5, 1.0); also monotone warps. Measured m = 400:
  0.3535 → 0.179 / 0.208 / 0.211 (exact DP 0.082 per issue); m = 101:
  1.10 → 0.61 / 0.67 / 0.72.
- `multires_refinement_respects_lambda` — penalised objective non-increasing
  for λ ∈ {0.1, 10}; λ = 1e6 keeps the warp no farther from identity than the
  coarse warp.
