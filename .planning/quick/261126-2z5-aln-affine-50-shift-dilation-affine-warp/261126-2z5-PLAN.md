# 261126-2z5 — ALN-AFFINE (GH #50): shift / dilation / affine warp registration

## Goal
Linear warp registration h(t) = a·t + b (classes None / Shift / Dilation / Affine) of curves to a
template (mean re-estimated each iteration, fixed curve, or closure), minimising an L2,
normalised-L2 or (uncentred) Pearson dissimilarity as in R fdacluster 0.4.2; and make the warp
class selectable in `align_cluster_fd` (default Elastic = current behaviour, bit-identical).

## Public API (alignment/affine.rs, re-exported in alignment + crate root)
- `LinearWarpClass { None, Shift, Dilation, Affine }`, `AffineMetric { L2, NormalizedL2, Pearson }`,
  `AffineDomain { Full, Overlap }`
- `AffineRegistrationConfig` (metric, domain, extrapolation [reuses ShiftExtrapolation], bounds
  max_dilation/max_shift = fdacluster warping_options (0.15, 0.15), grid_size, max_iter, tol,
  center_warps, optim_tol)
- `affine_registration(data, argvals, class, ShiftTemplate, &config) -> AffineRegistrationResult`
- `affine_warp_curves(data, argvals, dilations, shifts, extrapolation) -> FdMatrix`
- clustering_advanced: `AlignClusterWarp { Elastic (default), None, Shift, Dilation, Affine }`,
  new `AlignClusterConfig.warp_class` + `.linear_config`, new `AlignClusterResult.affine_warps`.

## Algorithm
Registered curve gᵢ = fᵢ∘hᵢ⁻¹ (fdacluster warps the grid: value fᵢ(tⱼ) sits at hᵢ(tⱼ); shift
sign = fdars shift convention). Per iteration: template from registered curves → per-curve
bounded optimisation of dist² (coarse grid + golden section in 1-D / Nelder–Mead in 2-D, warm
start) → optional centring (mean dilation 1, mean shift 0 via composition with H⁻¹) → stop on
max parameter change ≤ tol. Domain Full: compare on argvals with extrapolation. Domain Overlap:
compare on linspace over the intersection of hᵢ([t₀,t_{m−1}]) and the template domain (fdacluster).
L2 + Overlap + dilation/affine is rejected (as fdacluster: not dilation invariant).
Clustering: seeded template init (same RNG), assign by argmin dissimilarity over templates,
per-cluster centring + mean template; empty-cluster re-init as elastic path.

## Validation
- Exact recovery of known synthetic affine warps (fixed + mean template, both domains, all classes).
- Invariants: identity on already aligned data, centring constraints, metric invariances
  (Pearson amplitude-scale invariance), hand-computed metric values.
- Golden: fdacluster 0.4.2 `fdakmeans` (k = 1 affine/pearson, shift/l2, dilation/pearson; k = 2
  shift/l2) comparing frame-invariant relative warps hᵢ∘h₁⁻¹ and memberships.
- Bit-identity: default `align_cluster_fd` == explicit Elastic.
