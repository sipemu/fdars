## Design notes
- Warp acts on the grid as in fdacluster: registered `gᵢ = fᵢ ∘ hᵢ⁻¹`; shift sign matches fdars shift registration.
- fdacluster "bpd" = SRVF elastic on an interval → mapped to the existing `Elastic` class (default, untouched path).
- L2 + Overlap + dilation/affine rejected (fdacluster raises the same error); Full domain allows L2 for all classes.
- Documented deviations (module docs): fixed template grid vs fdacluster's moving one (frame pinned by warp centring),
  bounds on total warp vs per-iteration increment, grid+golden/Nelder–Mead vs BOBYQA, observed-only mean on overlap,
  plain argmin assignment (no LP minimum cluster size).
