# Plan — #73 DTW family gaps

## Goal
Close the four DTW-family caveats of #73, additively (univariate results bit-identical),
each validated against a reference implementation.

## Public API (all additive)
1. **Multivariate series** — a series is a `d × m` `FdMatrix` (channels × time points, aeon's
   `(n_channels, n_timepoints)`; column-major ⇒ time-major interleaved flat buffer).
   - `dtw_distance_multivariate`, `dtw_path_multivariate`, `dtw_pairwise_distance_multivariate`
     (dependent DTW: local cost `‖a − b‖₂^p`, p = 2 → squared Euclidean across channels = aeon/tslearn).
   - `dtw_barycenter_averaging_multivariate` → `DbaMultivariateResult` (`d × size` barycenter);
     new `DbaInit::CustomMultivariate(FdMatrix)`.
   - `dtw_kmeans_multivariate` → `DtwKMeansMultivariateResult` (+ `predict`);
     new `DtwKMeansInit::CentroidsMultivariate(Vec<FdMatrix>)`.
   - Elastic family: `<name>_distance_multivariate`, `_pairwise_distance_multivariate`,
     `_cost_matrix_multivariate`, `_alignment_path_multivariate` for DDTW, WDTW, WDDTW, ADTW,
     ERP, EDR, TWE, MSM (independent = per-channel sum, dependent = vector costs), LCSS.
2. **shape-DTW** (aeon `shape_dtw_*`): `shape_dtw_distance`, `_pairwise_distance`,
   `_cost_matrix`, `_alignment_path` (+ `_multivariate`), `ShapeDtwDescriptor`
   {Identity (aeon default), Paa, Dwt, Slope, Derivative} (sktime ShapeDTW descriptors), `reach`.
3. **k-NN**: `dtw_k_nearest_neighbors(queries, references, k, p, window)` → `DtwKNearestNeighbors`;
   the 1-NN search becomes the k = 1 case of the same top-k cascade (bit-identical output + stats).
4. **Lower bounds**: `lb_improved(x, y, p, window)` (Lemire 2009, p ≥ 1),
   `lb_enhanced(x, y, p, window, v)` (Tan, Petitjean & Webb 2019).

## Algorithm notes
- Elastic recipes move from `&[f64]` to a channel-interleaved `Ser { v, d }` view; per-cell
  costs `sqe`/`euc` start from `0.0` exactly like aeon's `_univariate_squared_distance`, so
  `d = 1` performs the same floating-point operations as before (bit-identical).
- DTW/DBA/k-means internals get a channel count `d`; `d = 1` dispatches to the existing
  univariate code paths.
- shape-DTW: edge-pad by `reach`, descriptor of each length-`2·reach+1` subsequence per channel,
  DTW on descriptors, distance = Σ raw squared cost along aeon's strict-`<` traceback
  (including aeon's numpy negative-index wrap-around at the borders).
- LB_Improved: `LB_Keogh(x, env y) + Σ_j dist(y_j, env(H)_j)`, `H = clamp(x, env y)`; envelope
  over the window's admissible rows/cols (general windows, unequal lengths).
- LB_Enhanced: `V` L-shaped left/right bands (min admissible cell cost) + LB_Keogh on the middle
  rows; `V_eff = min(V, (min(n, m) − 1)/2)`, LB_Keogh fallback when `V_eff = 0`.

## Validation
- aeon 1.6.0: multivariate DTW / elastic family (distance, cost matrix, path, pairwise), shape-DTW
  (identity; other descriptors via sktime 1.3.0 transformers fed as `transformed_x/_y`).
- tslearn 0.10.0: multivariate `dtw_path`, `dtw_barycenter_averaging`, `TimeSeriesKMeans` (fixed init).
- LB_Improved: Lemire's `lbimproved` C++ (p = 1) and Tan's `LbEnhanced` Java `LbImproved` (p = 2);
  LB_Enhanced: Tan's Java `LbEnhanced` (p = 2). Plus `LB ≤ DTW` / `LB_Keogh ≤ LB_Improved` on
  many random pairs and windows.
- k-NN: exact equality with brute force for many k / windows / p, k = 1 equals `dtw_nearest_neighbor`.
- Bit-identity: multivariate `d = 1` == univariate; existing goldens unchanged.
