# 261126-j5n — ALN-CAV RBFGS optimiser coverage gaps (#67)

## Goal
Every remaining elastic entry point accepts a `WarpOptimConfig` (RBFGS + #49 DP
options) via additive `_with_config` functions; the RBFGS coarse-DP seed honours
the DP options; band semantics for RBFGS are defined; the DP ↔ RBFGS λ scales
are reconciled with an opt-in conversion. Defaults bit-identical.

## Public API (additive)
- `WarpOptimConfig::band_frac: f64` (default 0 = off) — Sakoe–Chiba band for
  every `_with_config` entry point (DP: index corridor; RBFGS: banded seed +
  projection, see below).
- `WarpOptimConfig::lambda_scale: WarpLambdaScale` (`Native` default, `Dp`,
  `Fdasrsf`) + `WarpOptimConfig::rbfgs_lambda_factor(q1, q2)`.
- `elastic_align_pair_nd_with_config`, `elastic_distance_nd_with_config`,
  `karcher_mean_nd_with_config` (alignment/nd.rs).
- `elastic_align_pair_constrained_with_config` (constrained.rs).
- `karcher_median_with_config`, `robust_karcher_mean_with_config`
  (robust_karcher.rs).
- `align_to_target_with_config` (set.rs).
- `karcher_mean_closed_with_config` (closed.rs).

## Algorithms
- N-d DP with options: per-channel Euclidean normalisation (as the classic
  N-d DP), edge weight summed over channels with the `nbhd_dim` / `dp_cost` /
  `dp_scl` / L2Gam|L2Psi / band options; classic options dispatch to the
  unchanged classic N-d DP. N-d RBFGS: multi-channel `rbfgs_warp_multi`
  seeded by the N-d DP with options on the coarse grid.
- Landmarks + RBFGS: segmented DP warp (with options) first; each segment is
  mapped affinely onto [0,1]² (q̃2 carries √(L_r/L_c)), solved by RBFGS seeded
  from the DP segment, mapped back with the landmark values set exactly. The
  segment penalty is the global one restricted to the segment: L2Gam/L2Psi
  on κ·γ̃' (κ = L_r/L_c, new `pen_slope` in the RBFGS problem), Roughness
  rescaled by L_r²/L_c³, λ normalised with the global Euclidean norms;
  Geodesic (non-additive) with λ > 0 is rejected.
- RBFGS band: seed DP banded on the coarse grid; after RBFGS the warp is
  projected pointwise onto |γ(t) − t| ≤ b (clamp; preserves monotonicity and
  endpoints); when the projection is active the better (RBFGS objective) of
  projected RBFGS warp and projected seed is returned.
- λ conversion (1-D, L2Gam/L2Psi): E_dp = span·c1c2·E_rb when
  λ_rb = φ·λ_dp, φ = scl·‖q1‖‖q2‖/(‖q1ᶠ‖‖q2ᶠ‖) (Euclidean norms on the input
  grid and on the scl-refined grid); φ → 1 as m → ∞.
