# Summary — ALN-NDDOWN (#54)

## Public API added (all additive, in `alignment::curve_shape`, re-exported from `alignment`, crate root; result types in prelude)
- `curve_shape_karcher_median(curves, cfg, max_iter, tol)` → `CurveShapeKarcherResult`
  (fdasrvf `multivariate_karcher_mean(ms="median")`: Weiszfeld direction
  `Σ vᵢ/‖vᵢ‖ / Σ 1/‖vᵢ‖`, damped step 0.5, medoid initialisation; energy history `Σ dᵢ`).
- `curve_shape_tsrvf(mean, curves)` → `CurveShapeTsrvfResult {tangent_vectors (n × d·m),
  distances, aligned_srvfs, rotations, gammas, seeds}`; `curve_shape_tangent_to_curve(mean, v)`.
- `curve_shape_depth(curves, cfg)` → `CurveShapeDepthResult {amplitude_depth, phase_depth,
  amplitude_distances, phase_distances}` (fdasrvf `curve_depth` formulas, row medians incl. 0 diagonal).
- `curve_shape_outlier_detection(curves, &CurveShapeOutlierConfig)` → `CurveShapeOutlierResult`;
  `CurveShapeOutlierConfig {shape, centre: CurveShapeCentre {Mean, Median(default)},
  threshold_method: OutlierThreshold (Tukey 1.5 default), alpha, max_iter=20, tol=1e-3}`.
- `curve_shape_boxplot(median_result, cfg)` / `curve_shape_boxplot_from_aligned(median_srvf,
  aligned_srvfs, aligned_curves, scale, cfg)` → `CurveShapeBoxplot` (median, distances, r50,
  ralpha, Q1/Q3/Q1a/Q3a indices + curves, whisker SRVFs + curves, whisker_distance,
  outlier_indices, min/max extremes); `CurveShapeBoxplotConfig {alpha=0.05, k_a=1.0}`.
- `curve_shape_confidence_interval(curves, shape, &CurveShapeCiConfig)` → `CurveShapeCiResult
  {mean, bootstrap_means, bootstrap_distances, radius, lower_band, upper_band}`;
  `CurveShapeCiConfig {n_bootstrap=200, confidence_level=0.95, max_iter=15, tol=1e-3, seed=42}`.
- Internal: `outlier::{tukey_fence, quantile_threshold}` made `pub(super)` (reused, unchanged).

## Deviations / notes
- Karcher mean bit-identity: the mean path is the same code (sweep → `align_all` is the identical
  parallel iterator; vbar/energy/step/initialisation expressions unchanged); no separate hash test.
- Shape CI follows the issue text (bootstrap of the Karcher mean, like the 1-D
  `shape_confidence_interval`), not fdasrvf `shape_CI` (tangent-Gaussian sampling + box plot);
  documented in the rustdoc.
- Box plot: if no curve lies outside the 50% region and below the whisker, the min/max extremes
  fall back to the Q1/Q3 curves (fdasrvf errors in that case). Region sizes are clamped to ≥ 2.
- Golden references use fdasrvf 2.5.0 (installed); the issue asks for ≥ 2.5.1. The box plot
  golden involves no DP so it is unaffected; the depth golden is tolerance-based anyway.
