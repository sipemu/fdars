# Plan — ALN-NDDOWN (#54): R^d curve downstream analyses

## Goal
Extend the R^d shape-space curves of `alignment::curve_shape` (#48) to TSRVF, depth,
outlier detection, box plot and shape confidence regions. Additive, non-breaking.

## Public API (all in `alignment::curve_shape`, re-exported from `alignment` + crate root)
1. **Karcher median** `curve_shape_karcher_median(curves, cfg, max_iter, tol)` →
   `CurveShapeKarcherResult` (fdasrvf `multivariate_karcher_mean(ms = "median")`:
   Weiszfeld tangent step `v̄ = Σ vᵢ/‖vᵢ‖ / Σ 1/‖vᵢ‖`, medoid initialisation, energy `Σ dᵢ`).
   The mean code path is untouched (bit-identical).
2. **TSRVF** `curve_shape_tsrvf(mean, curves)` → `CurveShapeTsrvfResult` (align new or
   training curves to the Karcher mean, log map into the tangent space at μ:
   sphere-tangent + closure-normal projection, layout as `shooting_vectors`);
   `curve_shape_tangent_to_curve(mean, v)` (exp map + SRVF inversion).
3. **Depth** `curve_shape_depth(curves, cfg)` → `CurveShapeDepthResult` (fdasrvf
   `curve_depth`: pairwise amplitude/shape distance and phase distance of the optimal warp;
   `amp = 1/(1+median_j d_ij)`, `phase = ((2+π)/π)(1/(1+median_j dx_ij) − 2/(2+π))`).
4. **Outliers** `curve_shape_outlier_detection(curves, &CurveShapeOutlierConfig)` →
   `CurveShapeOutlierResult` (shape distance to Karcher median/mean, reusing
   `OutlierThreshold` Tukey/quantile rules from `outlier.rs`).
5. **Box plot** `curve_shape_boxplot_from_aligned(median_srvf, aligned_srvfs, aligned_curves,
   scale, &CurveShapeBoxplotConfig)` and `curve_shape_boxplot(median_result, cfg)` →
   `CurveShapeBoxplot` (port of fdasrvf `curvebox_data`: 50%/(1−α) central regions,
   quartile pair by the energy criterion, whiskers `k_a·IQR`, outliers, extremes).
6. **Shape CI** `curve_shape_confidence_interval(curves, shape_cfg, &CurveShapeCiConfig)` →
   `CurveShapeCiResult` (bootstrap of the Karcher mean, bootstrap means aligned to the
   full-sample mean, geodesic confidence radius + pointwise coordinate bands). fdasrvf's
   `shape_CI` is model-sampling + box plot; the issue asks for the bootstrap of the
   Karcher mean (consistent with the 1-D `shape_confidence_interval`) — documented.

## Validation
- Golden: fdasrvf 2.5.0 `curvebox_data` on analytic SRVF fields (innerprod_q2 overridden
  with trapezoid so arithmetic matches) → distances, indices, whisker, outliers to 1e-10.
- Golden (tolerance): fdasrvf `curve_depth(rotated = FALSE)` depths on a small curve set.
- Invariants: TSRVF of training curves == shooting vectors; tangent ⟂ μ and ⟂ closure
  normals; exp(log) round trip; depth invariant to rotating all curves; depth max at the
  central member of a 1-parameter family; planted outlier flagged and depth-minimal;
  median robust to an outlier vs mean; bootstrap CI radius covers the true template.
