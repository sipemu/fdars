# Quick 261126-78p: ALN-ELDIST (GH #57) — aeon elastic-distance family

## Goal
Add aeon's elastic distances DDTW, WDTW, WDDTW, ADTW, ERP, EDR, TWE, MSM, LCSS to
`fdars-core::metric`, each with `<name>_distance`, `<name>_pairwise_distance` (self + cross,
parallel), `<name>_cost_matrix`, `<name>_alignment_path`, numerically matching aeon 1.6.0.

## Public API
- New module `metric::elastic_family` (one generic padded-lattice DP core + one file per distance).
- `fn <name>_distance(x: &[f64], y: &[f64], window: DtwWindow, <params>) -> Result<f64, FdarError>`
- `fn <name>_cost_matrix(..) -> Result<FdMatrix, FdarError>` (aeon shapes: n×m; LCSS (n+1)×(m+1);
  DDTW/WDDTW in derivative coordinates (n−2)×(m−2))
- `fn <name>_alignment_path(..) -> Result<ElasticAlignment, FdarError>` (`path`, `distance`)
- `fn <name>_pairwise_distance(data: &FdMatrix, other: Option<&FdMatrix>, window, <params>) -> Result<FdMatrix, FdarError>`
- Parameters with aeon names/defaults: `g` (WDTW/WDDTW 0.05; ERP 0.0 — univariate `g_arr` ≡ `g`),
  `warp_penalty` (ADTW 1.0), `epsilon: Option<f64>` (EDR, None → max(std)/4), `epsilon` (LCSS 1.0),
  `nu`/`lmbda` (TWE 0.001/1.0), `c` + `independent` (MSM 1.0/true).
- `DtwWindow` gains (non_exhaustive, additive) `SakoeChibaFraction { window }` and
  `ItakuraFraction { max_slope }` — exact ports of aeon `create_bounding_matrix(window=…)` /
  `(itakura_max_slope=…)`. Existing variants unchanged (tslearn semantics).

## Algorithm
Shared `Lattice` ((n+1)×(m+1) padded table, border/out-of-band init per distance) filled over
`DtwWindow::row_bounds`; per-distance cell closure; shared `compute_min_return_path` traceback
(np.argmin first-min tie rule); LCSS-specific traceback. Pairwise via `self_distance_matrix` /
`cross_distance_matrix` (parallel).

## Validation
Golden values from aeon 1.6.0 (venv ~/.cache/fdars-golden-venv) for distance, cost matrix,
alignment path on small random series incl. unequal lengths, windowed (fraction) and Itakura
variants; aeon bounding-matrix goldens; invariants (symmetry, identity, pairwise = pointwise).
