# Plan — ALN-LB (GH #58): DTW lower bounds, EAPrunedDTW, exact 1-NN

## Goal
Add DTW lower bounds and exact fast 1-NN search to `fdars-core/src/metric/` (new file `dtw_lb.rs`),
consistent with `dtw_distance_windowed` (cost `Σ|x_i − y_j|^p`, **no root**) and `DtwWindow`.

## Public API (re-exported from `metric` + crate root)
- `DtwEnvelope { lower, upper }`
- `lb_envelope(x, radius)` — tslearn `lb_envelope` (window `[i−r, i+r]`, Lemire streaming min/max)
- `lb_envelope_windowed(y, query_len, window)` — envelope of `y` over the admissible row ranges of any `DtwWindow`
- `lb_keogh(query, &envelope, p)` — Σ |violation|^p (tslearn reports `sqrt` of the p=2 value)
- `lb_kim(x, y, p)` — max(first+last, |max−max|^p, |min−min|^p)
- `lb_webb(x, y, p, window)` — Webb & Petitjean (2021) LB_Webb, generalised to arbitrary windows via row/column admissible ranges; returned as max(LB_Webb with MinLRPaths, LB_Webb_NoLR) so LB_Keogh ≤ LB_Webb holds unconditionally; requires p ≥ 1 (convex cost)
- `dtw_distance_early_abandon(x, y, p, window, cutoff) -> Result<Option<f64>>` — EAPrunedDTW (Herrmann & Webb 2021): bit-identical to `dtw_distance_windowed` when ≤ cutoff, `None` otherwise
- `dtw_nearest_neighbor(queries, references, p, window) -> Result<DtwNearestNeighbors>` — cascade LB_Kim → LB_Keogh (candidates visited in LB_Keogh order) → LB_Webb → EAPrunedDTW with LB_Keogh cumulative suffix bound; parallel over queries; lowest index on ties; pruning counters

## Validation
- tslearn 0.10.0 goldens for `lb_envelope` and `lb_keogh` (squared)
- invariants on many random pairs and windows (Sakoe radius 0..k, Itakura, aeon fractions, unequal lengths): LB_Kim ≤ DTW, LB_Keogh ≤ LB_Webb ≤ DTW
- EAPrunedDTW: bit-identical to `dtw_distance_windowed` for cutoff ≥ DTW, None for cutoff < DTW, exact at cutoff == DTW
- 1-NN equals brute force (index + distance bits) on random data, several windows, p ∈ {1, 2, 1.5, 0.5}
- hand cases: lb_kim, envelope by naive scan
- criterion bench `dtw_lb_benchmarks` 1-NN vs brute force (`--quick`)
