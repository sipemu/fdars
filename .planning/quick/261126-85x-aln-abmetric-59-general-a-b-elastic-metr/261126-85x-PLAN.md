# Quick 261126-85x — ALN-ABMETRIC (GH #59): general (a,b) elastic metrics for planar curves

## Goal
Add the Kurtek–Needham F_{a,b}-transform and the (a,b)-elastic metric family for planar
curves to `alignment::curve_shape`, selectable via a `metric` option of `CurveShapeConfig`
(default SRVF = bit-identical to the current behaviour).

## Conventions (geomstats 2.8.0 / Kurtek–Needham 2018)
- Metric `g_c(h,k) = ∫ a²⟨D_s h,N⟩⟨D_s k,N⟩ + b²⟨D_s h,T⟩⟨D_s k,T⟩ ds` (a bending, b stretching).
- `F_{a,b}(c) = 2b |c'|^{1/2} (c'/|c'|)^{λ}`, λ = a/(2b), complex power taken on the
  continuous lift θ(t) of the tangent angle with θ(0) = atan2 ∈ (−π, π] (geomstats k = 0 branch).
- SRVF is a = 1, b = 1/2 (λ = 1, 2b = 1) — NOT a = 1/2, b = 1 as the issue text says.
- Reparametrisation acts exactly like on SRVFs: F(c∘γ) = (F(c)∘γ)√γ' → shared DP engine.
- Rotation by φ multiplies F by e^{iλφ} (up to the lift e^{2πiλk}) → full SO(2) Procrustes in
  F-space is the exact quotient over rotations *and* lifts; curve rotation = ψ/λ.

## Public API
- `CurveShapeMetric { Srvf (default), Elastic { a, b } }` + `CurveShapeConfig.metric`.
- `ab_transform(beta, a, b)`, `ab_transform_inverse(f, a, b)` (left inverse for λ ≤ 1, right
  inverse for λ ≥ 1).
- All curve_shape functions (align/distance/matrix/Karcher mean+median/PCA/TSRVF/depth/
  outliers/boxplot) accept the Elastic metric for open planar curves (d = 2, closed = false).

## Validation
- geomstats 2.8.0 golden: pointwise F for 5 (a,b) pairs on a spiral with angle wrap; inverse;
  no-reparam distance at k=9 (exact discretisation) and k=2001 (vs our trapezoid, rel 1e-5).
- Invariants: Elastic{1,1/2} ≡ SRVF (1e-10); reparam/rotation invariance; symmetry; triangle
  inequality on random triples (no-reparam, rotation); d_reparam ≤ d_noreparam; Karcher mean
  of rotated/warped copies recovers the shape; SRVF default bit-identity.
