# Quick 261126-t4g — ALN localised group differences (GH #76)

## Goal
Align, then localise *where* two groups differ (amplitude and phase), with error control, as regions on the time grid.

## Public API (additive)
- `crate::regions` (new shared module): `SignificanceDirection`, `SignificantRegion`, `significant_regions`,
  `significant_regions_from_se` moved here from `explain::pdp` (old paths re-export the same items);
  new `DifferenceRegion` (+ `difference_regions_from_band`, `difference_regions_from_pvalues`).
- `inference::scb_two_sample_band` -> `ScbTwoSampleBand { estimate, lower, upper, half_width, critical_value, regions, rejected }`;
  `scb_two_sample_test` refactored onto a shared core, numerically identical.
- `inference::itp_pointwise_pvalues(&ItpResult, argvals, ItpDomainMapping)` and `itp_regions(..., alpha)`
  (B-spline only; Fourier components are frequencies -> InvalidParameter).
- `alignment::elastic_local_difference_test(data, argvals, labels, &LocalDifferenceConfig)`
  -> `LocalDifferenceResult { amplitude, phase, alignment, ... }`.

## Algorithm
Label-free `karcher_mean_with_config` on all curves; amplitude test on `aligned_data`, phase test on
`γ_i(t) − t` (default) or `ψ_i = √γ_i'`; each with ITP (default: B-spline, closure-adjusted p mapped to
grid) or SCB (Degras band on the mean difference). Regions split by the sign of the pointwise mean
difference A − B; phase Positive ⇔ A later.

## Validation
- R fdatest 2.1.1 ITP2bspline: replicate its permutation loop with fixed seed, check Rust closure
  (rank transform + p-value matrix + pval.correct) reproduces pval.matrix and corrected.pval exactly.
- SCB band decision == `scb_two_sample_test` decision; bit-identity of the test vs pre-refactor values.
- Synthetic seeded studies: amplitude bump only; timing shift only; null FWER (long study #[ignore]).
