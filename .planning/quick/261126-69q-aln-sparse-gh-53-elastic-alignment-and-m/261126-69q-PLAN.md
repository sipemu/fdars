# ALN-SPARSE (GH #53): elastic alignment and means for sparse / irregular curves

## Goal
Port the polygon/SRV-spline approach of Steyer, Stöcker & Greven (Biometrics 2023), R `elasdics`
1.1.3 (`align_curves`, `compute_elastic_mean`), so curves in R^d (d >= 1, incl. 1-D functions)
observed at different, sparse point sets can be aligned and averaged without a common grid.

## Public API (new module `alignment::sparse`, additive)
- `SparseCurve { points: FdMatrix (d x m), param: Option<Vec<f64>> }`, `SparseCurve::new`,
  `SparseCurve::with_param`, `sparse_curves_from_irreg(&IrregFdata)` (1-D functions).
- `sparse_elastic_align_pair(&SparseCurve, &SparseCurve, &SparseAlignConfig) -> SparseAlignmentResult`
  (open and closed curves; elasdics `align_curves`).
- `sparse_elastic_mean(&[SparseCurve], &SparseElasticMeanConfig) -> SparseElasticMeanResult`
  (open curves; `SparseMeanType::{Smooth, Polygon}` = linear / constant SRV spline on `knots`;
  elasdics `compute_elastic_mean`), with `srv_eval` / `mean_curve` evaluators.

## Algorithm
- Curves as polygons: SRV piecewise constant `q_k = Δβ_k / sqrt(Δt_k |Δβ_k|)`; parametrisation
  given or arc length; duplicate points removed; closed curves closed by appending the start.
- Alignment polygon-to-polygon: elasdics coordinate-wise analytic maximisation of
  `Σ_k sqrt(Δs_k ∫_{t_k}^{t_{k+1}} <q_k, p(u)>_+^2 du)` (even/odd sweeps, closed: periodic
  extension + shift pre-alignment).
- Mean: alternate L2 spline fit of warped SRVs (least squares on hat / indicator basis) and
  alignment of each curve to the current mean; polygon: discrete aligner; smooth: exact piecewise
  integrals of the linear SRV spline + coordinate-wise 1-D maximisation (elasdics uses
  `constrOptim` with numerical `integrate`).

## Validation
- Goldens from R elasdics 1.1.3 (scripts `golden_elasdics_align.R`, `golden_elasdics_mean.R`):
  align_curves examples (open, reparametrised template, closed), compute_elastic_mean spiral
  example (polygon 15 knots, smooth 11 knots).
- Invariants: inserted collinear points leave distances unchanged; reparametrisation invariance;
  identical curve on different grids -> mean equals the curve; dense-grid limit vs `karcher_mean`.
