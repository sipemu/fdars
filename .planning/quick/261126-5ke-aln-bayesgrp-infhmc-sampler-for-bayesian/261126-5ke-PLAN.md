# 261126-5ke — ALN-BAYESGRP (GH #52) part 2: infHMC sampler

## Goal
Finish #52: add an infinite-dimensional (preconditioned) HMC sampler for the warp
updates of `bayesian_align_group`, selectable via `BayesianGroupConfig::sampler`
(default `Pcn`, bit-identical to 065279f0).

## Reference
fdasrsf 2.7.5 `fdawarp.time_warping_bayes_infHMC` + `bayesian_functions.infhmc_step(_batch)`,
`dual_avg_step`, `bayes_warp_geom` (port of fdasrvf_MATLAB; Beskos et al. 2011):
- splitting integrator: half kick `v -= ε/2 · C ∇nll`, exact prior rotation
  `(c, v) ← (c cos ε + v sin ε, v cos ε − c sin ε)`, half kick; momentum `v ~ N(0, C)`;
  `H = nll + c'C⁻¹c/2 + v'C⁻¹v/2`; trajectory leaving support → reject.
- leapfrog count uniform on 1..L (L = 10), initial ε = √h = 0.1,
  dual-averaging (Hoffman & Gelman 2014 Alg. 5; t0 = 10, γ = 0.05, κ = 0.75, μ = log 10ε₀,
  ε ≤ π/2) per curve during burn-in, target 0.65, then ε = exp(log ε̄).
- template: conjugate Gaussian Gibbs draw; σ²: inverse-gamma Gibbs.

## API (additive)
- `enum BayesianSampler { Pcn (default), InfHmc }` (non_exhaustive).
- `BayesianGroupConfig` new fields: `sampler`, `hmc_step_size` (0.1), `hmc_max_leapfrog` (10),
  `hmc_adapt` (true), `hmc_target_accept` (0.65).
- `BayesianGroupChain::warp_step_sizes` (final ε per curve; empty for pCN).
- `BayesianGroupResult`: `ess_sigma2`, `ess_log_likelihood`, `ess_warps` (Geyer IPS ESS summed
  over chains), `warp_bimodality` (Sarle's coefficient of pooled warp-area draws) and
  `multimodal_curves` (BC > 5/9 or between-chain spread).

## Model kept identical to the pCN sampler
Same target: warp prior N(0, diag(warp_sd²)) truncated to ψ ≥ 0, quadratic B-spline template prior
N(0, diag(tmpl_sd²)), IG(α₀, β₀). infHMC preconditions by the warp prior covariance; the template
is drawn exactly from its Gaussian full conditional (as the reference).

## Validation
1. Hash test: default (pCN) result hash pinned to the pre-change value.
2. Exact gradient of SSE w.r.t. Fourier coefficients vs central finite differences (several
   coefficient vectors, incl. 0).
3. Warp kernel invariance: one curve, fixed template/σ², 1 harmonic → posterior mean/var of the
   2 coefficients by 2-D quadrature vs infHMC chain (within MC error).
4. Full sampler invariance: tiny problem, no centring — infHMC vs long pCN posterior means and
   variances of σ², warp areas within MC error (batch-means SE).
5. Mixing: ESS/iteration infHMC vs pCN at equal iterations; R̂ — numbers reported.
6. Acceptance in target range after adaptation; determinism; warp recovery.
7. ESS vs AR(1) theory; bimodality coefficient hand values.
