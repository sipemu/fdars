# ALN-DPACC (#49): configurable DP neighbourhood, `scl` refinement, candidate pruning

## Goal
Make the elastic DP engine's move set configurable (fdasrvf `nbhd_dim` / fdasrsf `grid_dim`),
add fdasrsf-style cost refinement and an exact piecewise-linear (DP2) edge cost, and exact
candidate pruning — all through `WarpOptimConfig`, defaults bit-identical.

## Public API (additive, `WarpOptimConfig` is sealed → new fields with defaults)
- `WarpOptimConfig::nbhd_dim: usize` (default 7 → the 35-move `COPRIME_NBHD_7`).
- `WarpOptimConfig::dp_scl: usize` (default 1; 1..=64) — SRSFs linearly resampled `dp_scl`
  times finer to evaluate each edge cost; path stays on the input grid (fdasrsf `DP` `scl`).
- `WarpOptimConfig::dp_cost: DpEdgeCost` — `PiecewiseConstant` (default, classic) or
  `PiecewiseLinear` (fdasrsf ≥ 2.7.4 `DP2`: exact integral of the linearly interpolated SRSFs).
- `WarpOptimConfig::dp_prune: bool` (default false) — skip sources whose cost already ≥ the
  target's best (exact for non-negative edge weights, i.e. always under a validated config).
- New enum `DpEdgeCost` re-exported from `alignment` and crate root.

## Algorithm
- `DpGridOptions { nbhd, scl, cost, prune }` threaded through `dp_grid_solve_banded` →
  `dp_fill_grid` → `dp_relax_cell` (nbhd slice instead of the const; prune check).
- `dp_alignment_core_with_penalty` → `dp_alignment_core_opts` (default opts = classic).
  Uniform-grid √(dr/dc) table generalised to `(d+1)²`.
- Refinement: q1,q2 resampled on an index-uniform fine grid; coarse edge (sr,sc)->(tr,tc)
  evaluated with the integer walk on fine indices (×scl) — same rslope/span.
- Linear cost: integer walk with per-sub-interval end-point interpolation, (f0²+f0f1+f1²)/3.

## Validation
- Existing FNV hash tests unchanged (bit-identity of the refactor) + new: explicit default
  options == classic; prune on == prune off bit-for-bit (pair, self-dist, Karcher, λ>0, band).
- DP objective with nbhd 10 ≤ nbhd 7 (superset of moves) on the DP's own path cost.
- Independent fine-grid cost of the warp decreases with nbhd/scl/linear; warped-self-distance
  residual (f vs f∘γ, γ = t+0.25t(1−t), m=80) decreases from the ≈0.02-class floor.
- Golden: fdasrsf 2.7.5 `optimum_reparam(method="DP2", grid_dim=10)` warps vs
  `nbhd_dim=10 + PiecewiseLinear` on 3 cases.
- Criterion bench group `dp_options` in alignment_benchmarks.rs.
