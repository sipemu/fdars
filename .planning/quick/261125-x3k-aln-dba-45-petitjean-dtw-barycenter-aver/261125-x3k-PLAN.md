# Quick 261125-x3k — ALN-DBA (GH #45): Petitjean DTW Barycenter Averaging

## Goal
Hard-DTW Barycenter Averaging (Petitjean et al. 2011) with mean / medoid / custom
initialisation and an optional `DtwWindow`, plus a DTW k-means that uses DBA as
its centroid step (no DTW k-means existed before). Additive, non-breaking.

## Public API
- `metric::dba` (new): `dtw_barycenter_averaging(data, &DbaConfig) -> Result<DbaResult>`,
  `DbaConfig { max_iter=30, tol=1e-5, window=None, init=Mean, barycenter_size=None, weights=None }`,
  `DbaInit { Mean, Medoid, Custom(Vec<f64>) }`, `DbaResult { barycenter, cost, n_iter, converged }`.
- `dtw_kmeans` (new module): `dtw_kmeans(data, &DtwKMeansConfig) -> Result<DtwKMeansResult>`,
  `DtwKMeansInit { KMeansPlusPlus, Centroids(FdMatrix) }`, `DtwKMeansResult::predict`.
- Re-exports at `metric`, crate root and prelude (siblings are there).

## Algorithm
tslearn `dtw_barycenter_averaging` (MM form): per iteration compute `dtw_path(bary, x_k, p=2, window)`
for every series (parallel), cost = Σ w_k cost_k / Σ w_k, update
`b_i = Σ_k w_k Σ_{(i,j)∈p_k} x_k[j] / Σ_k w_k |{j:(i,j)∈p_k}|`; stop when |Δcost| < tol or the
cost rises. Mean init = pointwise mean (linear interpolation to `barycenter_size`); medoid =
argmin_i Σ_k w_k DTW²(x_i, x_k). k-means: tslearn `TimeSeriesKMeans(metric="dtw")` loop —
assign by DTW cost, DBA warm-started from the previous centroid, stop on |Δinertia| < tol,
final reassignment; k-means++ seeding (greedy 2+ln k trials) with `seed + restart`.

## Validation
- tslearn 0.10.0 golden barycenters (mean, Sakoe-Chiba r=1, Itakura 2, size 12, weights,
  custom init, medoid init) and docstring examples; dtaidistance 2.5.1 `dba` / `dba_loop`.
- tslearn `TimeSeriesKMeans` labels + centers from a fixed init.
- Invariants: monotone cost, identical series → fixed point, radius-0 window = arithmetic mean,
  k-means labels are argmin, determinism.
