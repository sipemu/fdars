# 261126-b80 SUMMARY — joint_gauss_model amplitude–phase correlation (GH #80)

## Root cause (two parts)
1. `joint_score_mean_var` + `sample_joint_z` sampled each joint score
   independently (diagonal Gaussian) → cross-covariance lost (issue: corr −0.02).
2. Found while testing: after fixing (1) the correlation came back **reversed**
   (−0.986). Samples were built as `a ∘ γ` with `γ` in the alignment convention
   (`aligned_i = f_i ∘ γ_i`), but an observed curve is `aligned_i ∘ γ_i⁻¹`.
   fdasrsf 2.7.5 `fdawarp.joint_gauss_model` on the same data gives −0.991
   (same flip) and +0.991 when composing with `invertGamma(gam)` — confirming
   the inverse is the correct composition. `gauss_model` shared the bug.

## Fix
- `joint_score_mean_cov_factor`: full sample covariance + PSD square root via
  `nalgebra::SymmetricEigen`; `sample_joint_z` draws `mean + L z` (same RNG
  draw count).
- `warp_amplitude_sample`: sample = `a ∘ γ⁻¹` (`invert_warp`) in both
  `gauss_model` and `joint_gauss_model`; `warps` output unchanged, docs state
  the convention.

## Tests (generative.rs)
- `joint_cov_factor_reproduces_full_covariance` — rank-deficient hand matrix.
- `joint_gauss_model_preserves_amplitude_phase_correlation` — issue repro
  (data corr 0.999), requires sample corr > 0.8 (was −0.02 before; −0.986 with
  only part 1).
- `warp_amplitude_sample_inverts_alignment` — `aligned_i ∘ γ_i⁻¹ ≈ f_i`.
