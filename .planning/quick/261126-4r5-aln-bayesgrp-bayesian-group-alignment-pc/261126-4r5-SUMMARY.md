## Public API (additive; re-exported from `alignment`, crate root, prelude for the result)
- `bayesian_align_group(data: &FdMatrix, argvals: &[f64], &BayesianGroupConfig)
  -> Result<BayesianGroupResult, FdarError>`
- `BayesianGroupConfig` (sealed, `Default`): `n_iter, burn_in, thin, n_chains, seed, alpha0,
  beta0, pcn_betas, pcn_probs, warp_prior_sd, n_warp_harmonics, n_template_basis, n_points,
  center_every, credible_level, center_draws, init_dp`.
- `BayesianGroupResult`: posterior-mean (ψ-mean) / median warps + bands, aligned data,
  template SRSF + bands, template function + bands, σ² mean + interval, warp/template
  acceptance, split-R̂ (σ², log-lik, per-curve warp area), `mode_spread`, pooled draws,
  per-chain `BayesianGroupChain` (chain-mean warps, max-log-lik "mode" draw, traces).

## Model (fdasrsf 2.7.5 `time_warping_bayes` / `bayesian_functions`, source read in venv)
SRSF likelihood `q*(t) = q_i(γ_i)√γ_i' + N(0,σ²)` iid on the grid; warps `ψ = exp_1(Σ c φ)`,
prior sd `σ_g/j`; template quadratic B-spline (fdasrsf `create_basismatrix` knots), prior sd
`σ_q/⌈k/2⌉`, `σ_q = 5(P95−P5)`; σ² inverse-gamma Gibbs; Z-mixture pCN with fdasrsf defaults;
SqrtMeanInverse centring every 100 iterations. Chains via `iter_maybe_parallel!`, seed+k.

## Deviations (documented in module docs)
1. Warp basis = true tangent space at ψ=1 (sin/cos, j≥1); fdasrsf's `basis_fourier` has a
   non-tangent constant √2 column, so its warps need not end at 1.
2. Invalid proposals (ψ<0) are rejected (exact MH on truncated prior) instead of re-drawn.
3. γ normalised to end at 1.
4. `init_dp = true` default: chains start from DP alignment to the medoid template
   (projected + centred). Without it, identity-started chains often got stuck in poor modes
   (σ² 10–20× too large, warp error 0.3) within a few thousand iterations.
5. `center_draws = true` default: every retained draw is re-centred exactly (no
   re-projection) before summaries. Both 4 and 5 can be set `false` for fdasrsf behaviour.
6. `n_points = 0` (input grid) default instead of 200.

## Validation (14 tests + 1 `#[ignore]` long MC study + doctest)
- scipy/fdasrsf `create_basismatrix(linspace(0,1,11),6,3)` literals → B-spline basis 1e-12;
  partition of unity; warp basis orthonormal & tangent (trapz, 1e-12).
- Split-R̂ vs hand/numpy BDA3 formula (2 cases), numpy percentile literals.
- Bit-identical reruns; chain k of a multi-chain run == single chain seeded seed+k.
- Recovery: exponential warps (identity baseline error 0.11) recovered to < 0.05 max abs
  (measured ≈ 0.02); aligned spread < 20% of raw; acceptance in (0.01, 0.9).
- Summaries: all warps monotone, bands ordered, mode = max-log-lik draw, posterior-mean
  warps centred.
- Noise 0.002 → 0.03: σ² ×>1.5 and band width ×>1.2.
- Coverage of 95% pointwise bands, warps in model space: short study (3 seeds, 3000 it)
  measured **0.874**, asserted > 0.75; long `#[ignore]` study (10 seeds × 4 chains × 20000 it)
  measured **0.829** (0.822 with 30 template bases), asserted > 0.75. Under-coverage vs
  nominal is attributed to misspecification: noise is on f, so the SRSF noise is not iid
  Gaussian, plus discretisation bias of the template/SRSF (σ² floor ≈ 0.05 even noise-free).
- R̂ on an easy problem (5 curves, 1 harmonic, 4 chains × 24000 it): R̂(σ²) 1.012,
  R̂(loglik) 1.037, warps ≤ 1.002 (asserted < 1.1); mode spread < 0.02.
- fdasrsf 2.7.5 `time_warping_bayes(iter=20000, burnin=10000, nbasis=16, npoints=41,
  initcoef=zeros((6,6)))` averaged over numpy seeds 0–3 (`golden_time_warping_bayes.py`):
  our posterior-mean warps (4 chains, init_dp=false, center_draws=false) within **0.040**
  max abs (asserted 0.06; fdasrsf's own seed spread 0.047). Template peaks within 0.1 of
  fdasrsf's; fdasrsf's template is smeared (peak 0.72 vs true 1.0, σ² 0.4–0.8) whereas ours
  peaks at 0.93 (σ² 0.035), so a tighter template comparison is not meaningful.
- Validation errors (16 config cases + dims/non-finite/non-increasing argvals).
- Tests run ~3.5 s in debug.
