# ALN-BAYESGRP (GH #52): Bayesian group alignment (Z-mixture pCN, multi-chain)

## Goal
Joint posterior sampling of per-curve warps, the template SRSF and the noise variance for a
set of curves, after fdasrsf 2.7.5 `fdawarp.time_warping_bayes` (port of fdasrvf_MATLAB /
fdasrvf 2.6.0 `time_warping_bayes`), with deterministic multi-chain runs and
multimodal posterior summaries.

## Model (as in fdasrsf `time_warping_bayes` / `bayesian_functions`)
- Unit grid `t ∈ [0,1]`, `T = n_points` (0 → m). Curves linearly resampled, SRSF `q_i`.
- Warp i: shooting vector `v_i = Σ_k c_ik φ_k` in a Fourier basis; `ψ_i = exp_1(v_i)`,
  `γ_i = cumtrapz(ψ_i²)`. Prior `c_ik ~ N(0, (σ_g/j)²)`, `j` = harmonic index.
- Template `q* = B a`, B-spline basis of order 3 with `n_template_basis` functions
  (fdasrsf `create_basismatrix` knots); prior `a_k ~ N(0, (σ_q/⌈k/2⌉)²)`,
  `σ_q = 5·(P95−P5 of all q_i)`.
- Likelihood: `q*(t_j) = q_i(γ_i(t_j)) ψ_i(t_j) + ε`, `ε ~ N(0, σ²)` iid over grid points.
- `σ² ~ InvGamma(α0, β0)` → Gibbs `InvGamma(N T/2 + α0, SSE/2 + β0)`.
- Z-mixture pCN proposals (betas/probs mixture) for each `c_i` (one MH step per curve per
  iteration) and for `a`; MH ratio = likelihood ratio (pCN is prior-reversible).
- Centering every `center_every` iterations: `γ_I = SqrtMeanInverse(γ)`, `q* ← (q*, γ_I)`,
  `γ_i ← γ_i ∘ γ_I`, coefficients re-projected (as in reference).

## Deviations from the reference (documented)
- Warp basis is the proper tangent space at ψ=1 (`√2 sin/cos(2πjt)`, j = 1..M); fdasrsf's
  `basis_fourier` puts a constant `√2` first (not tangent), so its "warps" can leave [0,1].
- Invalid proposals (ψ < 0 somewhere) are **rejected** (exact MH under the truncated prior)
  instead of being re-drawn (reference re-draws, which is not exactly reversible).
- γ is normalised to end at 1 (no extrapolation past the domain).

## Public API
- `BayesianGroupConfig` (sealed, `Default`), `bayesian_align_group(data, argvals, &config)
  -> Result<BayesianGroupResult, FdarError>`, `BayesianGroupResult`, `BayesianGroupChain`.
- Multi-chain: `n_chains`, chain k seeded `seed + k`, run with `iter_maybe_parallel!`.
- Summaries: pooled posterior-mean (ψ-mean) and median warps, pointwise credible bands for
  warps / template SRSF / template function, σ² mean + interval, per-curve warp + template
  acceptance rates, per-chain posterior-mean warps and max-log-likelihood draw (modes),
  between-chain mode spread, split-R̂ for σ², log-likelihood and per-curve warp summaries.

## Validation
- Synthetic known warps (centred so their Karcher mean is identity): posterior mean warps
  recover truth; bands cover truth at near-nominal rate (fixed seeds, small MC; long study
  `#[ignore]`); acceptance in sane range; more data noise → wider bands / larger σ²;
  identical seeds → bit-identical; R̂ ≈ 1 on easy problem; invariants (monotone warps,
  band ordering, basis partition of unity / orthonormality); validation errors.
- fdasrsf 2.7.5 `time_warping_bayes` on one small case: posterior-mean warps / template
  compared within a loose documented tolerance (literals embedded).
