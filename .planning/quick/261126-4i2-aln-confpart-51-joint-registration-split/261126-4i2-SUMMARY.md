Files: `fdars-core/src/conformal/partial.rs`, `fdars-core/src/conformal/partial_tests.rs`.

## Paper fidelity (Wang, Kurtek & Zhang, JCGS 2026, PMC13160368)
Implemented: Algorithms 2/3 (SFCP amplitude, SFCPP phase): random training/calibration split,
Karcher template from training only, DP registration of calibration curves, responses
`f_i∘γ_i*` / `γ_i*`, predictor = observed prefix, Gaussian NW neighbourhood smoothing (eq. 4)
leave-self-out on the augmented calibration+new set (full conformal within calibration),
phase score = Fisher–Rao warp distance d_w, three predictor distances (L2, SRSF-L2, elastic).
Simplifications / deviations:
- Absolute amplitude residuals (two-sided intervals); paper writes signed residuals.
- Trial-value grid search replaced by an exact closed-form breakpoint scan (scores are affine
  in y); reported interval = convex hull of the conformal set (coverage preserved).
- Phase NW fit = pointwise convex combination of warps (paper does not pin this down).
  Phase set exact only via `phase_set_contains`; the envelope/radius come from a deterministic
  trial family (sphere geodesics from the centre toward each calibration warp), i.e. an inner
  approximation for display.
- Bandwidth: user value or median of pairwise predictor distances (symmetric => valid);
  the paper's Liang–Zhu–Barber efficiency tuning is NOT implemented.
- Fragmented / sparse observation regimes NOT implemented.
- No elastic FPCA / jfPCA component is needed by the method (NW smoother), so none is used.

## Validation (no packaged reference exists)
- Closed-form interval vs independent brute-force grid (20 random cases, 2e-4), b=0 split limit
  (hand-computed), unbounded case.
- Exact finite-sample rotation invariant: each of 16 exchangeable curves as the new curve =>
  covered count >= ceil((1-α)(n2+1)) pointwise (amplitude) and for phase; L2 at s≈0.43, SRSF at s=1.
- Monte-Carlo (seed 2026, 150 reps, n2 = 19, random s): amplitude/phase coverage
  α=0.1: 0.891/0.893; α=0.2: 0.782/0.787; α=0.3: 0.681/0.673 — asserted within
  [1-α-3sd, 1-α+1/(n2+1)+3sd].
- Width shrinks with calibration size (n2=9 vs 80: amp width 4.07 vs 2.95, phase radius 1.45 vs 1.06).
- s=1: full-window registration, `full_registration` identical to `elastic_align_pair`, bands narrower
  than for a 5-point prefix. Seed determinism (bitwise equal models/predictions; seed change changes split).
- Phase set structure: centre and all accepted trials are members, valid warps, extreme warp excluded.
