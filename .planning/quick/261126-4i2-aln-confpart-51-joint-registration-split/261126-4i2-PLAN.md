# ALN-CONFPART (#51): joint registration + split-conformal amplitude/phase prediction sets for partially observed curves

## Goal
Implement Wang, Kurtek & Zhang (JCGS 2026, "Joint Registration and Conformal Prediction for
Partially Observed Functional Data", PMC13160368) SFCP (amplitude) and SFCPP (phase) in
`fdars-core/src/conformal/partial.rs`.

## Public API (module `conformal`, re-exported at crate root)
- `PartialPredictorDistance { L2, Srsf, Elastic }` — distance d(X_i, X_i') between observed prefixes.
- `PartialConformalConfig` (sealed, `default()` + assign): alpha, cal_fraction, seed, distance,
  bandwidth (None = median heuristic), lambda, karcher_max_iter, karcher_tol, n_phase_radii.
- `partial_conformal_fit(data, argvals, &cfg) -> PartialConformalModel` — random split, Karcher
  mean template on the training part, registration of calibration curves to the template.
- `partial_conformal_fit_with_template(calibration, argvals, template, &cfg)` — independent template.
- `partial_conformal_predict(&model, observed_prefix, &cfg) -> PartialConformalPrediction`:
  partial registration (reuses `elastic_partial_match`), amplitude band (exact), phase set
  (exact membership `phase_set_contains`, plus centre / accepted-trial envelope / radius).

## Algorithm
- Responses: Y_i(t) = (f_i ∘ γ_i*)(t) (amplitude), γ_i* (phase), γ_i* = DP registration to template.
- Predictor: X_i = f_i restricted to the observed grid prefix [t_0, s] of the new curve.
- Neighbourhood smoothing (paper eq. 4): Gaussian NW over the n2+1 predictors, leave-self-out,
  test point included in calibration fits => full conformal within the calibration set.
- Amplitude: scores |S_i(t)| are affine in trial y -> exact closed-form interval per t
  (breakpoint scan; replaces the paper's trial-value grid search).
- Phase: Ŷ_i(y) = (1-b_i) m_i + b_i y (pointwise convex combo of warps), score d_w (Fisher–Rao
  sphere distance); exact membership test; trial warps along sphere geodesics from the centre.

## Validation
- Rotation invariant: for fixed exchangeable sample, each point in turn as test => covered
  fraction >= ceil((1-α)(n2+1))/(n2+1) exactly (amplitude per t and phase).
- Monte-Carlo coverage with fixed seed on synthetic warped data at several α, binomial tolerance.
- Width shrinks with more calibration data; s=1 degenerates (full-window registration, full
  registration exposed, bands no wider than for short prefixes); seed determinism.
