# Plan — ALN-WFDA (GH #61): Tang–Müller pairwise curve synchronisation (fdapace `WFDA`)

## Goal
Port R fdapace 0.6.0 `WFDA(Ly, Lt, optns)` (Tang & Müller 2008, Biometrika) to fdars-core for dense
regular-grid data: per curve, pairwise warps to a subset of other curves (monotone piecewise-linear
warps optimised under a penalty λ, or random search), truncated / weighted averaging of the pairwise
warps into the inverse warp, inversion, registration.

## Public API (new `alignment/wfda.rs`, re-exported from `alignment` and crate root)
- `WfdaChoice { Truncated (default), Weighted }`
- `WfdaCostMeasure { PairwiseFit (default), FdapaceLegacy }` — fdapace 0.6.0 computes the pairwise
  cost against one matrix element (linear index bug); `FdapaceLegacy` reproduces it bit-for-bit,
  `PairwiseFit` uses mean((ỹ_k∘h_ik − ỹ_i)²).
- `WfdaConfig` (`#[non_exhaustive]`, serde): choice, subset_prop 0.5, nknots 2, is_pwl true,
  seed 666, lambda None (→ fdapace default Vy·1e-4), cost_measure, truncation_quantile 0.9,
  optimiser max_evals / tol.
- `WfdaResult`: warps h_i, inverse_warps (argvals scale), aligned, costs, lambda, partners,
  pairwise_warps, pairwise_costs.
- `pairwise_synchronization(data, argvals, &WfdaConfig) -> Result<WfdaResult, FdarError>`

## Algorithm (mirrors fdapace source)
work grid w = (t − t0)/(T − t0); ỹ_i = y_i / max|y_i|; λ = 1e-4·sqrt(Σ_i ∫(ỹ_i − μ)²/(N−1));
K = round_half_even(subsetProp·(N−1)); candidates sampled with StdRng(seed + i);
PWL warp: knots at uniform [0,1] positions with heights (0, sort(x), 1), objective
Σ_j (ỹ_k(h(w_j)) − ỹ_i(w_j))² + λ Σ_j (h(w_j) − w_j)², box [1e-6, 1−1e-6]; fdapace uses BOBYQA,
fdars a box-projected Nelder–Mead with restarts (same local minimum from the identity start).
Random search: K² candidate warps (sorted uniforms), shared across pairs, minimum cost.
hInv = truncated mean (cost ≤ type-7 quantile 0.9) or 1/cost-weighted mean; h = inverse (R approx,
ties = mean); aligned = y_i∘h_i.

## Validation
- Golden: fdapace 0.6.0 + minqa 1.2.8 (`golden_wfda.R`, subsetProp = 1 → RNG-free): legacy
  truncated / weighted (unmodified WFDA), fixed-cost truncated / weighted / nknots 3 + λ 1e-3
  (WFDA with the one-line cost fix) — λ, h, hInv, aligned, costs.
- Invariants: identity on identical (scaled) curves, monotone warps with fixed endpoints, hInv
  equals the truncated / weighted average of the returned pairwise warps, h∘hInv ≈ id, recovery
  of known synthetic warps (up to the mean-warp normalisation), determinism with seed, errors.
