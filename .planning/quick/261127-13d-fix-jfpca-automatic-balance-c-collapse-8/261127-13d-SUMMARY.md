## #84
**Root cause:** `optimize_balance_c_raw` minimised `total − top-k explained` variance of
`[q_centered | c·shooting]`; the phase block's unexplained variance scales with c², so the
search was pulled to c → 0 (phase dropped).

**Fix (elastic_fpca.rs):** objective replaced with fdasrsf 2.7.5 `fdajpca.calc_fpca`/`find_C`:
rank-ncomp joint reconstruction → q̂ᵢ (mean + amplitude block), v̂ᵢ = phase block / c →
ψ̂ = exp_μψ(v̂) → γ̂ → q̃ᵢ = (q̂ᵢ, γ̂ᵢ⁻¹); dᵢ = ∫(q̃ᵢ − q0ᵢ)²; objective Σdᵢ²/N; bracket
(0, round(max q_aug)+1]. q0ᵢ rebuilt as (qnᵢ, γᵢ⁻¹) so `joint_fpca_from_alignment` (no raw
data) works the same. Search = 20-point grid scan + golden-section refine (tol 1e-5).
Applies to joint_fpca, joint_fpca_from_alignment, jfpca_fit, elastic_pfi/veesa_pipeline,
elastic PCR/changepoint joint paths when balance_c = None. `Some(c)` bit-identical (pin kept).
