# Quick 261127-13d: jfpca automatic balance_c (#84) + expfam citation venues (#85)

## #84 — automatic balance_c collapses to c≈0
**Root cause:** `optimize_balance_c_raw` minimised the SVD residual of
`[q_centered | c·shooting]` (total − top-k explained variance). That residual
scales with c² in the phase block, so it is monotone-ish decreasing as c→0 and
the search ends at the lower bracket: the joint model ignores phase.

**Fix:** use the fdasrsf 2.7.5 `fdajpca.calc_fpca` / `find_C` objective —
reconstruction error in the *original* SRSF space: for each curve rebuild
q̂ᵢ (amplitude part + mean) and v̂ᵢ = phase part / c from the rank-k joint
reconstruction, ψ̂ᵢ = exp_μψ(v̂ᵢ), γ̂ᵢ = ∫ψ̂ᵢ² (normalised), q̃ᵢ = (q̂ᵢ, γ̂ᵢ⁻¹),
dᵢ = ∫(q̃ᵢ − q0ᵢ)², objective Σdᵢ²/N; bracket (0, round(max q_aug)+1].
q0ᵢ is rebuilt from (qnᵢ, γᵢ⁻¹) so `joint_fpca_from_alignment` (no original
data) works identically. Search: coarse grid scan + golden-section refine
(robust to the shallow local minima the objective has; fdasrsf's Brent can
stop at the bracket end).

**Validation:** repro data from the issue (one Gaussian bump with location
shift 0.1·zᵢ, n=30, m=101): fdasrsf objective/selected C as reference
literals; regression test asserts automatic c is far from 0, first joint
score |corr| with z ≥ 0.95 (old: 0.42), and the fdars objective at the
selected c is ≤ objective at c≈0 and comparable to the fixed c=1 fit.
