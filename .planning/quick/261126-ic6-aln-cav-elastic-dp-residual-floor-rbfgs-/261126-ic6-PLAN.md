# 261126-ic6 — ALN-CAV elastic DP residual floor (#65)

## Goal
Diagnose why d(f, f∘γ) does not shrink with m (curve shape #48 ~0.02, (a,b) #59 ~0.04,
1-D #49 0.120 vs 0.070) and fix what's fixable additively.

## Hypothesis
The DP restricts the warp to piecewise-linear paths whose slopes come from the fixed
coprime set {dr/dc : dr,dc ≤ nbhd_dim}; the √γ' factor is therefore quantised with a
grid-independent resolution ~1/nbhd_dim → floor independent of m. Resampling/quadrature
errors (oracle warp) should be O(h²).

## Public API (additive)
- `CurveShapeConfig::warp_optim: WarpOptimConfig` (default = classic DP → bit-identical):
  method Dp/Rbfgs, nbhd_dim, dp_scl, dp_cost, dp_prune, max_iter, scl, penalty.
  Penalty weight stays `CurveShapeConfig::lambda`; `warp_optim.lambda` must be 0.
- serde derives on WarpOptimConfig + its enums (needed: CurveShapeConfig derives serde).
- `elastic_align_pair_closed_with_config` / `elastic_distance_closed_with_config` (1-D closed).

## Algorithm
- R^d DP with options (nbhd/cost/scl/penalty) summed over coordinates; default options →
  existing `geometry::dp_warp` unchanged.
- RBFGS generalised to d channels (cost Σ_c ‖q1_c − (q2_c∘γ)√γ'‖²); 1-D path bit-identical.
  Coarse start = R^d classic DP on ≤51 points.

## Validation
- Diagnostic table (ignored test, `--nocapture`): residual vs m ∈ {41,81,161,321} for
  default DP, nbhd10+PL, nbhd20+PL, RBFGS, oracle (exact inverse warp) — curve shape SRVF,
  (a,b) λ=2, 1-D.
- Bit-identity: existing curve_shape / ab / optim golden tests unchanged; default config ==
  explicit default warp_optim.
- New invariance tests with RBFGS and tighter bounds; RBFGS d=1 multi == 1-D path.
