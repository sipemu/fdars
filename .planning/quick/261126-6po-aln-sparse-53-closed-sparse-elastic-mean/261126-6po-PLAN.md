# ALN-SPARSE (GH #53, part 2): closed sparse elastic means + robust smooth goldens

## Goal
Finish #53: elastic means of CLOSED sparsely observed curves (elasdics 1.1.3
`compute_elastic_mean(closed = TRUE)` -> `fit_mean_closed`), and make the two near-limit
open smooth-mean golden assertions platform-robust.

## Public API (additive)
- `SparseElasticMeanConfig { closed: bool (default false), pen_factor: f64 (default 100) }`.
- `SparseElasticMeanResult { closed: bool, start_indices: Vec<usize> }`; `srv_eval` /
  `mean_curve` handle the periodic (closed) spline; `closure_residual()` helper.

## Algorithm (elasdics `fit_mean_closed`, generalised from d = 2 to any d)
1. Close every curve (append start); all-pairs starting-point pre-alignment
   (`pre_align_closed_srv_curves`), reference = argmin of summed squared distances; rotate
   every curve to its best start.
2. LS fit on the closed design (periodic hat basis, K coefficients; polygon: K indicators).
3. Loop: align each (rotated) curve to the mean with the open aligners (smooth: eps*100/i;
   polygon: fixed 1e-3 as elasdics), refit, stop criterion vs previous (penalised) coefs,
   one penalised gradient step `one_step_grad(pen_factor * i)`; at convergence one extra
   pure-closure step (`pen = Inf`).
   one_step_grad: direction g = (XᵀXc − Xᵀy)/pen + ∇P(c), P = |∫ p|p||² (closure residual
   squared, analytic gradient), line search = port of R's Brent `optimise` on [-1, 1].
4. Report params_optim in original point order (elasdics un-rotation), distances to the
   returned mean.

## Validation
- elasdics 1.1.3 goldens (script `golden_elasdics_closed_mean.R`): doc example (spirals,
  closed smooth, 11 knots), spirals closed polygon (15 knots), noisy closed shapes (smooth 9,
  polygon 13 knots). Polygon: tight (deterministic discrete aligner); smooth: tolerance-based.
- Invariants: closure residual ≈ 0, closed curve sampled on several grids -> mean recovers it,
  start-point rotation of input points leaves the mean/distances unchanged,
  reparametrisation invariance of the distances.
- Robust open smooth golden: objective(fdars) ≤ objective(R t_optim/coefs under fdars exact
  integrator) + tiny tol; mean-curve distance with an integration-error margin.
