# 261126-1a8 SUMMARY — ALN-CC (#47) Ramsay–Li continuous registration

## Public API (alignment module + crate root)
- `continuous_registration(data, argvals, target: Option<&[f64]>, &ContinuousRegistrationConfig)
  -> Result<ContinuousRegistrationResult, FdarError>`
- `ContinuousRegistrationCriterion { LeastSquares (crit=1), MinEigenvalue (crit=2, default) }`
- `ContinuousRegistrationConfig` (sealed; `default()` + assign): criterion, nbasis=6, norder=4,
  lambda=0, lfd_order=2, max_iter=50, tol=1e-8 (relative), n_fine=None (max(201,m)),
  max_template_iter=1, template_tol=1e-4, initial_coefficients=None; `validate()`.
- `ContinuousRegistrationResult`: registered_data, warps, w_coefficients (n×nbasis, col 0 ≡ 0),
  w_knots, criterion (per curve, incl. penalty, R scaling), target, n_iter, converged,
  n_template_iter.

## Implementation (`fdars-core/src/alignment/continuous.rs`)
- Warp `h = a + (b−a)·F/F(b)`, `F = ∫exp W`, W on a clamped B-spline basis (new small Cox–de Boor
  evaluator with derivatives, R knot convention; the crate's `bspline_basis` uses extended
  uniform knots, not R's), `c₁ ≡ 0` as in R. Penalty `K = ∫DᴸφDᴸφᵀ` by composite Gauss–Legendre.
- Curves/target interpolated with the in-module `rbfgs::NaturalSpline` (value + derivative);
  uniform fine grid with equal-weight means (R `xfine`); `F` by cumulative trapezoid, warps at
  argvals by cubic Hermite on `F` with exact `F' = exp W`.
- Optimiser: penalised Gauss–Newton + Levenberg–Marquardt on the exact gradient; crit 2 by
  variable projection (min-eigenvector `v`, envelope theorem). Steps only accepted on strict
  decrease; coefficient limit ±50 (R `climit`). Curves in parallel (`iter_maybe_parallel!`).
- Procrustes template passes when target = mean and `max_template_iter > 1`.
- Not reused: the alignment L-BFGS (`rbfgs.rs`) is a sphere/SRSF optimiser, and
  `smooth_monotone` fits a single curve to data (different objective); only the parameterisation
  idea is shared. The NaturalSpline from `rbfgs.rs` is reused.

## Deviations from R `register.fd`
- Discrete curves + natural spline instead of `fd` objects; outputs on `argvals`.
- R's gradient uses `D(y∘h)·∂h/∂c` (missing the `1/h′` chain-rule factor); fdars uses the exact
  gradient, GN Hessian and LM control instead of R's line search → lower-or-equal criterion,
  not bit-identical. Relative `tol` instead of absolute `conv`.
- `periodic = TRUE` not supported. Default W basis 6 cubic B-splines (R: 2 linear).
- `tf::tf_register(method = "cc")` was not used as a second reference (tf not installed).
