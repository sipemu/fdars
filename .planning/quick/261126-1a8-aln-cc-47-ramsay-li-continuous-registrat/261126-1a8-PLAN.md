# Quick 261126-1a8 — ALN-CC (GH #47): Ramsay–Li continuous registration

## Goal
Port R `fda::register.fd(y0fd, yfd, WfdParobj, conv, iterlim, crit=1|2)` (non-periodic) to
fdars-core: warp every curve to a target (default cross-sectional mean, optionally
Procrustes-iterated) with monotone warps
`h(t) = a + (b−a)·F(t)/F(b)`, `F(t) = ∫ₐᵗ exp W(s) ds`, `W = Σₖ cₖ φₖ` (clamped B-spline,
R `create.bspline.basis` convention; `c₁ ≡ 0` as in R), criteria
crit 1 = least squares `mean((y₀ − y∘h)²)` and crit 2 = Ramsay–Li minimum-eigenvalue
`2·λ_min(M)`, `M = [[mean y₀², mean y₀ y∘h],[·, mean (y∘h)²]]` (= R's `ee − dd`), plus
roughness penalty `λ·cᵀ K c`, `K = ∫ Dᴸφ Dᴸφᵀ`.

## Public API (alignment module + crate root)
- `enum ContinuousRegistrationCriterion { LeastSquares, MinEigenvalue (default) }`
- `struct ContinuousRegistrationConfig` (sealed, `default()`): criterion, nbasis, norder,
  lambda, lfd_order, max_iter, tol, n_fine, max_template_iter, template_tol.
- `struct ContinuousRegistrationResult`: registered_data, warps, w_coefficients (n×nbasis),
  criterion (per curve), target, n_iter, converged, n_template_iter.
- `fn continuous_registration(data, argvals, target: Option<&[f64]>, &config)`.

## Algorithm
Curves (and target) interpolated by the in-module natural cubic spline (`rbfgs::NaturalSpline`,
value + derivative). Uniform fine grid (R `xfine`), equal-weight means as in R. Per curve,
Levenberg–Marquardt-safeguarded Gauss–Newton on the exact gradient: crit 1 residual
`y∘h − y₀`; crit 2 via variable projection — with `v` the unit min-eigenvector of `M`,
`λ_min = mean((v₁y₀ + v₂ y∘h)²)` and the envelope theorem gives the exact gradient, so both
criteria reduce to one penalised GN least-squares loop. Steps accepted only on true-criterion
decrease (monotone criterion history). Curves in parallel (`iter_maybe_parallel!`).

## Validation
- Golden: R fda 6.3.0 `register.fd` (crit 1 and 2) on a two-bump warped example, embedded
  literals: warps / registered curves within documented tolerance, and fdars criterion
  evaluated at fdars coefs ≤ fdars criterion at R's coefs + tol. Basis values and penalty
  matrix vs `eval.basis` / `getbasispenalty`.
- Invariants: identity on aligned data, recovery of known W-family warps, monotone warps
  with fixed endpoints, crit-2 amplitude invariance, non-increasing criterion, FD gradient.
