# 261126-1n9 PLAN — ALN-CURVE (#48) R^d curve shape analysis

## Goal
Elastic shape analysis of curves β:[0,1]→R^d modulo translation, rotation (SO(d), optional
reflection), scale, reparametrisation, and — for closed contours — starting point (seed), with
closed-curve SRVF projection; Karcher mean, covariance and shape PCA under these quotients.
Reference: fdasrsf 2.7.5 `curve_functions` / `curve_stats.fdacurve`.

## Public API (new module `alignment/curve_shape/`, additive)
- `CurveShapeConfig` (sealed, `default()`+assign): rotation=true, allow_reflection=false,
  scale=true (remove scale ⇒ pre-shape sphere), include_length=false, closed=false,
  seed_search=true, seed_step=4, reparam=true, lambda=0, align_iter=2.
- `curve_srvf(beta, scale)`, `project_closed_srvf(q)`, `closure_residual(q)`,
  `optimal_rotation(q1, q2, allow_reflection)` (Kabsch/SVD).
- `curve_shape_align_pair(beta1, beta2, &cfg) -> CurveShapeAlignment`
  (aligned β2, q1, q2*, rotation, γ, seed, distance).
- `curve_shape_distance`, `curve_shape_self_distance_matrix`.
- `curve_shape_karcher_mean(curves: &FdCurveSet, &cfg, max_iter, tol)` →
  `CurveShapeKarcherResult` (mean, mean SRVF, aligned curves/SRVFs, rotations, γ's, seeds,
  shooting vectors, distances, energy, n_iter, converged).
- `curve_shape_karcher_covariance(&res)`, `curve_shape_pca(&res, ncomp)` →
  `CurveShapePcaResult` (+ `mode_shape` principal-geodesic reconstruction).
Curves are `FdMatrix` of shape d×m (row = coordinate, column = sample, implicit uniform grid
on [0,1]); sets are `FdCurveSet` (d matrices n×m).

## Algorithm
SRVF q = β'/√|β'| (numpy-style gradient, trapezoid L² on [0,1]); scale removal ⇒ ‖q‖=1 and
d = arccos⟨q1,q2*⟩ (+ log length ratio if include_length), else d = ‖q1−q2*‖.
Pair align: per seed candidate (closed: coarse stride + ±stride refine), alternate
Procrustes R = U diag(1,…,det) Vᵀ of ∫q1 q2ᵀ and R^d DP (shared coprime 35-move engine,
summed over coordinates, *no* per-coordinate renormalisation) for `align_iter` rounds; keep
best. Closed: q projected onto {∫q|q| = 0} (fdasrsf `project_curve` Newton scheme,
generalised to d), tangent projection via normal basis (generalised `find_basis_normal`).
Karcher: sphere (scale removed) or flat (scale kept) log/exp, step 0.5, fdasrsf stopping.
Covariance/PCA on shooting vectors (PCA in the L² metric via Gram SVD).

## Validation
Rotation recovery (exact without reparam), invariance to rotation/scale/reparam/seed/translation,
symmetry, closure residual after projection, fdasrsf 2.7.5 golden distances (open + closed)
and Karcher mean comparison, finite/PSD covariance, PCA reconstruction.
