# 261126-1n9 SUMMARY — ALN-CURVE (#48) R^d curve shape analysis

## Public API (`alignment::curve_shape`, re-exported from `alignment` + crate root; result types in prelude)
- `CurveShapeConfig` (sealed; `default()` + assign; `validate()`): rotation=true,
  allow_reflection=false, scale=true, include_length=false, closed=false, seed_search=true,
  seed_step=4, reparam=true, lambda=0, align_iter=2. Serde derive behind `serde`.
- Pairwise: `curve_shape_align_pair(beta1, beta2, &cfg) -> CurveShapeAlignment { beta1,
  beta2_aligned, q1, q2_aligned, rotation, gamma, seed, length1, length2, distance }`,
  `curve_shape_distance`, `curve_shape_self_distance_matrix(&FdCurveSet, &cfg)` (parallel).
- Geometry: `curve_srvf(beta, scale)`, `srvf_to_curve`, `closure_residual`,
  `project_closed_srvf`, `optimal_rotation(q1, q2, allow_reflection)`, `curve_from_set`,
  `curves_to_set`.
- Group statistics: `curve_shape_karcher_mean(&FdCurveSet, &cfg, max_iter, tol) ->
  CurveShapeKarcherResult` (mean, mean_srvf, aligned_curves, aligned_srvfs, rotations,
  gammas, seeds, shooting_vectors n×(d·m), distances, lengths, mean_length, energy, n_iter,
  converged, config); `curve_shape_karcher_covariance(&res)` ((d·m)², cap 10000 like
  `karcher_covariance_nd`); `curve_shape_pca(&res, ncomp) -> CurveShapePcaResult { scores,
  components (d×m, L²-orthonormal), eigenvalues, cumulative_variance, mean_tangent }` +
  `mode_shape(&res, k, coef)`.
- Layout: a curve is a `d × m` `FdMatrix` (row = coordinate, column = sample) on the implicit
  uniform grid of [0,1]; closed contours repeat the first sample at the end (fdasrsf).

## Implementation (`fdars-core/src/alignment/curve_shape/{mod,geometry,karcher,tests}.rs`)
- SRVF with numpy-style gradient, trapezoid L²; scale removal = unit-length curves (sphere,
  distance = chord-stable `2·asin(‖u1−u2‖/2)` = arccos⟨u1,u2⟩), flat L² with scale kept,
  optional log-length term (fdasrsf `scale=True`).
- Rotation: Kabsch SVD of ∫q1q2ᵀ (nalgebra), det-sign fix unless reflections allowed.
- Reparam: R^d DP on the shared `dp_grid_solve` / `dp_edge_weight_core` engine with the edge
  weight summed over coordinates, **without** the per-coordinate renormalisation that
  `elastic_align_pair_nd` applies (keeps the R^d Euclidean geometry). Shared engine untouched.
- Procrustes ↔ DP alternation (`align_iter` rounds, best kept) — never worse than fdasrsf's
  single rotation-then-DP pass.
- Closed: damped-Newton closure projection (fdasrsf `project_curve`, step 0.35/0.2,
  generalised to R^d with the exact Jacobian ‖q‖²I + 3∫qqᵀ, tol 1e-10); seed search coarse
  stride `seed_step` + full refinement within ±(seed_step−1); closure-normal tangent
  projection (generalised `find_basis_normal` + Gram–Schmidt).
- Karcher: sphere log/exp (step 0.5, fdasrsf) or flat (step 1 = exact average of aligned
  SRVFs); init at curve 0 (fdasrsf); stop on ‖v̄‖<tol, energy increase (keeps previous mean)
  or max_iter; curves aligned in parallel (`iter_maybe_parallel!`). PCA in the L² tangent
  metric via the n×n Gram matrix (SymmetricEigen), no d·m cap.
- pmat complexity of the new module: max cognitive 18 (≤ 23).

## Validation (22 unit tests + 8 doctests)
- Exactness: Procrustes recovers 2-D/3-D rotations and reflections to 1e-12; s·R·β+c is
  recovered (distance < 1e-10, rotation = Rᵀ, DP keeps identity); closed contour with
  sample seed shift + rotation + scale recovered exactly (asymmetric contour, seed unique);
  flat Karcher mean = mean(√sᵢ)·q exactly; many-poses Karcher mean SRVF exact to 1e-10.
- Invariants: closure residual < 1e-9 after projection, idempotent, norm preserved, curve
  reconstructs closed; distance invariance to warp/rotation/scale/translation/seed within
  the DP floor; near-symmetry; alternation monotone; shooting vectors tangent (⟂ q and the
  closure normals, 1e-10); PCA components L²-orthonormal, eigenvalues = score variances,
  one-parameter family → 2 PCs > 90 %; size-and-shape distance (√2−1)√L and length term
  ln2/2 exact; for d=1 the curve DP returns exactly the 1-D `elastic_align_pair` warp.
- fdasrsf 2.7.5 golden (`golden_curve_shape.py` here): `elastic_distance_curve` open 2-D
  no-rotation 0.10563 vs 0.10641, open 3-D 0.12491 vs 0.12387, closed (rotation+seed)
  0.36366 vs 0.36458 and vs 0.36519 for a rotated+seed-shifted copy (fdars gives the
  identical value for both) — all within 5e-3 (fdasrsf's own T=50…400 spread is 1–2e-3);
  with rotation fdars 0.10222 < fdasrsf 0.10593 (fdasrsf rotates in coordinate space).
  `fdacurve.karcher_mean(rotation=True)`: fdars mean energy 0.00802 < fdasrsf mean's
  0.00973 (fdasrsf stops early at ‖v̄‖ = 0.018), mean-to-mean distance 0.024 < 0.05.
- Tolerances for warp invariance are set by the DP discretisation floor, measured both for
  the shared fdars engine and for fdasrsf on the same configurations (fdasrsf: 0.012 at
  T=80 / 0.030 at T=40 open; 0.087 for the closed moved case where fdars gets 0.049).

## Deviations
- fdasrvf (R) golden values not used: installed fdasrvf is 2.5.0 and the issue pins
  ≥ 2.5.1 (DP numerics changed); fdasrsf 2.7.5 (≥ 2.7.4) is the reference.
- fdasrsf's quirks deliberately not reproduced: gradient step 1/T and Σ/T inner product
  (fdars uses the 1/(m−1) grid + trapezoid), coordinate-space rotation in
  `elastic_distance_curve` (fdars uses SRVF-space Procrustes, which is optimal).
- Covariance is plain Euclidean on the sampled shooting vectors (as fdasrsf); PCA uses the
  L² (trapezoid-weighted) tangent metric. With `scale=false` statistics live in the flat
  size-and-shape space instead of fdasrsf's appended raw-length coordinate.

## Remaining / follow-ups (not required by #48)
- Warp accuracy is limited by the shared 35-move DP (residual ≈0.02 at m=80 for
  self-distances; same for 1-D alignment and fdasrsf). A gradient refinement of γ with the
  ALN-RBFGS optimiser (`rbfgs.rs`) for R^d would lower this floor.
- Downstream N-d items (depth, boxplot, shape CI, TSRVF for curves) are ALN-NDDOWN; geodesic
  path under rotation/seed and `sample_shapes` not added.
