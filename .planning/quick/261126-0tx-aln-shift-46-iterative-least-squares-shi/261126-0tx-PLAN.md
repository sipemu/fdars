# Plan — ALN-SHIFT (#46): iterative LS shift registration + landmark shift

## Goal
Parity with scikit-fda 0.10.1 `LeastSquaresShiftRegistration` (iterative modified
Newton–Raphson, template re-estimated each pass: mean / fixed / callable) and
`landmark_shift_deltas` / `landmark_shift_registration`. Additive; the existing
golden-section `least_squares_shift_registration` is untouched (identical results).

## Public API (alignment + crate root)
- `ShiftExtrapolation { Boundary (default), Linear, Periodic, Zeros }`
- `shift_curves(data, argvals, shifts, extrapolation, restrict_domain) -> ShiftedCurves`
- `ShiftTemplate<'a> { Mean (default), Fixed(&[f64]), Custom(&dyn Fn(&FdMatrix) -> Vec<f64>) }`
- `IterativeShiftConfig { max_iter=5, tol=1e-2, step_size=1, restrict_domain=false, extrapolation, initial }` (sealed) + `validate()`
- `iterative_shift_registration(data, argvals, template, &config) -> IterativeShiftResult`
- `LandmarkLocation<'a> { Mean (default), MidRange, Fixed(f64), Custom(&dyn Fn(&[f64]) -> f64) }`
- `landmark_shift_deltas`, `landmark_shift_deltas_multi` (K landmarks/curve, LS common shift),
  `landmark_shift_registration(data, argvals, landmarks, location, &LandmarkShiftConfig) -> LandmarkShiftResult`

## Algorithm
skfda `_compute_deltas` port: derivative of unshifted curves (np.gradient edge_order=2),
per iteration shift → template → optional restriction to the commonly observed interval →
δ += step·∫(x−μ)Df/∫Df² (fdars sign δ = −d_skfda); stop when max|Δδ| ≤ tol or max_iter.

## Validation
- Golden values from scikit-fda 0.10.1 (`golden_shift.py`): 5 registration configs
  (default/linear, bounds 10 iters, fixed template periodic, median callable + zeros +
  step + initial, restrict_domain) + landmark deltas/registration (mean, fixed+restrict).
- Restrict-domain: also against skfda with SciPy simpson patched to fdars' even-N rule.
- Invariants: relative-shift recovery, template curve → zero shift, max_iter=0, constant curve,
  extrapolation hand values, NumPy gradient values, input validation.
