# 261126-m5e — ALN-CAV missing options (#72)

## Goal
A. `continuous_registration`: R `register.fd(periodic = TRUE)` + preset for R's default W basis.
B. `partial_conformal_*`: (2) simultaneous sup-norm amplitude bands, (1) valid data-driven
   bandwidth tuning, (3) fragmented / sparse observation settings.

## Public API
- `ContinuousRegistrationConfig::periodic`, `ContinuousRegistrationConfig::r_defaults()`,
  `ContinuousRegistrationResult::shift`.
- `PartialAmplitudeBand { Pointwise (default), Simultaneous }`, `PartialBandScale { Constant, TrainingSd, Custom }`,
  config fields `band`, `band_scale`, `bandwidth_candidates`, `tuning_fraction`;
  `PartialObservation { Fragments, Sparse }`, `partial_conformal_predict_observed`,
  `partial_conformal_select_bandwidth`.

## Algorithms
- Periodic: coefficient 0 of W becomes the shift δ (active), registered curve y(wrap(h+δ)),
  Jacobian column ∂/∂δ = Dy(h+δ); spline over 3 concatenated periods.
- Simultaneous: scores sup_t |Y−Ŷ|/σ(t) on the leave-self-out NW augmented fit; exact superset
  band c ± R σ with R = k-th smallest of A_i/(1−b_i), A_i = sup|a_i − b_i c|/σ.
- Tuning: held-out tuning part T of the calibration curves; h* = argmin mean band width over
  leave-one-out rotations within T; final sets from the remaining calibration curves. h* is a
  function of T only → exact finite-sample validity.
- Fragments: d_prod = Σ λ_j d(f|J_j, g|J_j), λ_j ∝ |J_j|; sparse: Euclidean on values
  (calibration curves linearly interpolated). Registration info via elastic_partial_match per fragment.

## Validation
R fda 6.3.0 goldens (periodic, default W); FD gradients; shift recovery; FNV pins of defaults;
exact rotation counts (simultaneous, fragments, sparse, fixed tuning set); seeded MC coverage.
