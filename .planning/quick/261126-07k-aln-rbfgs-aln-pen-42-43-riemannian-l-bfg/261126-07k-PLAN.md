# Quick 261126-07k — ALN-RBFGS (#42) + ALN-PEN (#43)

## Goal
Riemannian L-BFGS warp optimiser over l = √γ̇ on the unit Hilbert sphere (port of
fdasrsf 2.7.5 `rbfgs.rlbfgs` / `_rbfgs_reparam`, Huang–Gallivan–Srivastava–Absil),
seeded by a coarse (≤ 51 point) DP warp, selectable on pairwise / distance /
distance-matrix / Karcher entry points; warp penalties applied inside the objective
(`l2gam`, `l2psi` pointwise in DP; all four incl. `roughness`, `geodesic` in RBFGS).
DP + existing first-order penalty stays the default, bit-identical.

## Public API (additive)
- `WarpOptimMethod { Dp (default), Rbfgs }`
- `WarpObjectivePenalty { L2Gam (default, = existing DP penalty), L2Psi, Roughness, Geodesic }`
- `WarpOptimConfig { method, lambda, penalty, max_iter (30), scl (3) }` (sealed, `Default`)
- `elastic_align_pair_with_config`, `elastic_distance_with_config`,
  `elastic_self_distance_matrix_with_config`, `elastic_cross_distance_matrix_with_config`,
  `karcher_mean_with_config` — all `Result<_, FdarError>`.
- Doc-only deprecation of post-hoc Tikhonov `WarpPenaltyType::{SecondOrder, Combined}`.

## Algorithm
- Reuse soft-DTW L-BFGS primitives (`two_loop_lbfgs`, `lbfgs_dot`, `lbfgs_hessian_scale`,
  made `pub(crate)`) by working in x = √w ⊙ l coordinates (trapezoid metric → Euclidean).
- Exact discrete cost/gradient (cumtrapz adjoint), natural cubic spline for q2, barrier
  B(l) with fading ω, exp-map steps, parallel translation of BFGS pairs, cautious update.
- DP generalised to an arbitrary pointwise edge penalty via a monomorphised closure; the
  existing λ(slope−1)²dt closure is passed unchanged for the default path.

## Validation
- Bit-identity: default config vs every existing entry point (λ = 0 and λ > 0).
- Warps valid (monotone, boundary-exact); RBFGS cost ≤ DP-warp cost (same discretised cost);
  synthetic known-warp recovery; finite-difference gradient checks of cost and penalties.
- Penalty behaviour: larger λ ⇒ warp closer to identity / smoother; DP rejects
  roughness/geodesic with λ > 0 (fdasrsf semantics).
- Golden: fdasrsf 2.7.5 `optimum_reparam(method="RBFGS")` warps/costs embedded as literals.
