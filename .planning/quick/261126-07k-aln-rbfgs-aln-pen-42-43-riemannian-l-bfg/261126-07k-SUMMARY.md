## Implementation
- `alignment/rbfgs.rs`: port of fdasrsf 2.7.5 `rbfgs.rlbfgs` + `_rbfgs_reparam`
  (Huang–Gallivan–Srivastava–Absil): l = √γ̇ on unit L² sphere (trapezoid metric), coarse
  ≤51-pt DP seed, `scl`-refined grid, natural cubic spline for q2, exact discrete gradient
  (cumtrapz adjoint), barrier with fading ω, exp-map Armijo line search, parallel-translated
  BFGS pairs, cautious update, fdasrsf stopping rules; with λ>0 also starts from identity and
  keeps the lower cost. Reuses soft-DTW `two_loop_lbfgs` / `lbfgs_dot` / `lbfgs_hessian_scale`
  (made `pub(crate)`, no numeric change) via x = √w ⊙ l coordinates.
- DP: `dp_alignment_core_with_penalty` (generic edge-penalty closure); classic
  `dp_alignment_core_banded` passes the unchanged `dp_lambda_penalty` (l2gam); new
  `dp_l2psi_penalty`.
- Pairwise / distance-matrix / Karcher internals now thread `&WarpOptimConfig`; classic
  functions pass `WarpOptimConfig::classic_dp(lambda)`.

## Validation
- Bit-identity: FNV hashes of f64 bit patterns of classic outputs (pair, self/cross matrices,
  Karcher m=60 coarse+fine, banded Karcher, penalized SecondOrder; λ=0 and 0.3) recorded on
  the pre-change commit c1f088a4 in a scratch worktree; the new code reproduces them, and the
  default `*_with_config` equals the classic functions exactly (also non-uniform grid).
- Golden: fdasrsf 2.7.5 (`pip install fdasrsf` in `~/.cache/fdars-golden-venv`)
  `optimum_reparam(method="RBFGS")` and `method="DP"` warps for 3 analytic SRSF pairs
  (m=41, 41, 101), script `golden_rbfgs.py`. Measured: sup|γ−γ_fdasrsf| 0.006 / 0.001 / 0.009;
  cost within 0.02%–2.7% of fdasrsf's; documented tolerance 0.015 / 5%.
- RBFGS cost ≤ DP-warp cost on the same discretised cost (m = 41, 41, 101, 151; e.g.
  6.2e-4 vs 1.7e-3); warps monotone + boundary-exact; known-warp recovery sup error 0.0044
  (DP 0.0057), asserted < 0.01; identical curves → identity; deterministic.
- Finite-difference checks of cost gradient for all four penalties and the barrier;
  natural spline vs scipy 1.18.1 values; parallel transport isometry/tangency.
- Penalties: DP l2psi λ=0 == classic, monotone pull to identity, λ=1e4 → exact identity;
  hand-computed edge penalties; RBFGS all four penalties with λ=1e5 pull to identity and lower
  phase distance; roughness λ ∈ {0,1,100} gives bending energy 6.6 → 9e-5 → 1e-8.
  DP + Roughness/Geodesic with λ>0 → `InvalidParameter`.
