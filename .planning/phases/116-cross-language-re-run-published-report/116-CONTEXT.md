<decisions>
## Implementation Decisions

### Report location & format
- Full report lives at `documentation/PERFORMANCE.md` (tracked — `docs/` is gitignored). The README "Performance" section (currently one sentence) is rewritten into a short speed story that links to it.
- README speed story is SHORT: one headline table (fdars vs scikit-fda vs R at the largest N×M point per op), 2–3 honest takeaway lines, link to the full report.
- Tables are GENERATED by a new script `benchmarks/render_report.py` from the committed CSVs (reproducible); narrative prose is hand-written.
- Markdown tables only — no committed images/plots.

### Before/after framing
- "Before" = the Phase 113 baseline, snapshotted to `benchmarks/results/comparison_baseline.csv` (committed) BEFORE the re-run overwrites `comparison.csv`. The report diffs the two.
- Honest framing (milestone honesty clause): elastic alignment is NOT significantly faster (Phase 114 verdict: CIs overlap, hot path already near-optimal); the headline win is `face_covariance` ~3.45× (Phase 115, non-overlapping CIs); SVD documented near-optimal (faer thin SVD already the production path under `linalg`). Never fabricate or inflate a speedup.
- Rust-only ops (e.g. `face_covariance`) appear in a separate "fdars internal before/after" table, clearly labeled as having no scikit-fda/R comparator.
- Significance display: mean ± 95% CI plus a "significant?" column (non-overlapping CI). Cells failing the noise gate (RSD ≥5% or CI-width ≥5%) are flagged and never headlined.

### Re-run scope
- FULL re-run of all three ecosystems (fdars criterion, scikit-fda, R) on the same grid N ∈ {100,300,500} × M ∈ {50,200}; all `*_NUM_THREADS=1`; `env.json` refreshed for the after-run.
- Noisy headline cells (e.g. `functional_boxplot` RSD ~28% in baseline): raise criterion sample size / measurement time for the headline cells until they pass the noise gate; any cell still failing is flagged in the report.
- Numeric-agreement gate unchanged: fail-closed, runs BEFORE any timing is recorded (Phase 113 correlation-family metric for depth/boxplot/FPCR; FPCA corr>0.99; smoothing abs<1e-3; elastic L-inf<1e-2).
- Head-to-head is single-threaded only (fairness); the `parallel` feature is mentioned qualitatively in prose, no multi-thread tables.

### Scaling analysis & reproduction
- N×M scaling: per-op per-library time grid + empirical scaling exponents (log-log slope in N and in M) computed by `render_report.py`, compared to theoretical complexity (e.g. elastic O(N²·M²)).
- Reproduction instructions: step-by-step from a clean clone — Python venv from `benchmarks/requirements.lock`, `renv::restore()` from `benchmarks/renv.lock`, the single `run_all.py` full-run command, `render_report.py`, expected runtime + disk/`target/` footprint.
- Methodology disclosure: thread pinning; versions + BLAS backend + CPU from `env.json`; agreement tolerances; noise gate definition; the R `fda::pca.fd` vs Simpson-weighted-SVD footnote (locked in Phase 113 — SVD-matched is gated/comparable, `pca.fd` is ecosystem-realistic); criterion settings.
- `benchmarks/test_render_report.py` pytest unit tests, consistent with existing `test_*.py` harness tests.

### Claude's Discretion
- Exact table layouts/column names, the scaling-exponent fitting details, which cells count as "headline", the criterion sample-size bump values, and the README story wording — within the honesty + reproducibility constraints above.

</decisions>
