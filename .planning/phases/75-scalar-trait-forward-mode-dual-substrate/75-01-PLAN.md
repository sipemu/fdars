<objective>
Deliver DIF-01: the in-crate numeric substrate for forward-mode automatic differentiation. A `Scalar` trait defines the arithmetic/transcendental op set the differentiable FDA subset (Phase 76) will be written against; a forward-mode `Dual` number (value + tangent) implements it via chain rules; `Scalar` is also implemented for `f64` as a zero-cost passthrough so f64-instantiated generic code is numerically identical to today.

Purpose: Phase 76 makes elastic distance + FPCA scores generic over `Scalar`; Phase 77 exposes the public gradient API. This phase builds ONLY the substrate and its self-contained tests — no FDA operation is made generic here.

Output: A new single-file module `fdars-core/src/autodiff.rs` (registered as `pub mod autodiff;` in `lib.rs`) with the `Scalar` trait, the `Dual` struct, both `Scalar` impls, seed/extract/diff helpers, and inline three-tier tests (known-answer <=1e-10, finite-difference <=1e-6, f64 parity via assert_eq!).
</objective>
