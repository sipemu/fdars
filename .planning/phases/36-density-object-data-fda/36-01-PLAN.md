Open with a `//!` module-doc block that: names the R baseline `fdadensity` 0.1.4, cites the LQD reference Petersen and Mueller 2016 (Annals of Statistics 44(1):183-218), gives a minimal `use fdars_core::density_fda::{lqd_transform, inverse_lqd};` example, and includes a "Divergences from fdadensity" subsection documenting (a) linear_interp used for quantile inversion instead of natural cubic spline (round-trip L∞ ~5e-3 vs ~1e-5, negligible for smooth densities on >=101-pt grids) and (b) silent input normalization.     Implement three public Result-returning fns exactly per the 36-PATTERNS.md "Core function signatures" and the RESEARCH exact numeric chains:

    1. `normalize_density(vals: &[f64], argvals: &[f64]) -> Result<Vec<f64>, FdarError>` — validate length match (InvalidDimension), reject any value < 0 (InvalidParameter), reject argvals not strictly increasing (InvalidParameter), compute `trapz(vals, argvals)`, reject integral < 1e-15 (InvalidParameter, all-zero), return vals scaled by 1/integral. RESEARCH §Code Examples has the canonical body.

    2. `lqd_transform(density: &[f64], argvals: &[f64], n_quantile_pts: Option<usize>) -> Result<Vec<f64>, FdarError>` — per DENS-01 RESEARCH §Pattern 1: validate (all dens > 0 not merely >= 0, since -log(0) is +inf; length match; argvals strictly increasing). Normalize via `normalize_density`. Compute `cdf = cumulative_trapz(&dens_norm, argvals)` (starts at 0). Compute `lqd_raw[i] = -dens_norm[i].ln()`. Build uniform `t_grid` of length `n_q = n_quantile_pts.unwrap_or(argvals.len().max(101))` as `i/(n_q-1)` over 0..n_q. Map each t via `linear_interp(&cdf, &lqd_raw, t)` to get ψ. Return ψ. Guard: if any ψ is non-finite return `FdarError::ComputationFailed`.

    3. `inverse_lqd(psi: &[f64], t_grid: &[f64], target_argvals: &[f64]) -> Result<Vec<f64>, FdarError>` — per DENS-01 RESEARCH §Pattern 2, ALL FIVE STEPS including the mandatory Step-2 rescaling (theta_psi): validate (psi.len()==t_grid.len(), t_grid strictly increasing, target_argvals strictly increasing, psi all finite). Compute `exp_psi[i]=psi[i].exp()`, `q_raw = cumulative_trapz(&exp_psi, t_grid)`, add `lb = target_argvals[0]`. Rescale Q to the target support: `q_range = q_raw.last - q_raw.first`; `d_range = target_argvals.last - lb`; `q_scaled[i] = (q_raw[i]-q_raw[0]) * d_range / q_range + lb`. Compute `dens_raw[i] = (-psi[i]).exp()`. Dedup adjacent equal `q_scaled` values (keep first, drop the paired dens_raw) to keep the interpolation x-axis strictly monotone. Interpolate `dens[k] = linear_interp(&q_scaled_dedup, &dens_raw_dedup, target_argvals[k])` for each target point. Renormalize the result via `trapz` so it integrates to 1. Return it. This guarantees a normalized non-negative density.

    Do NOT omit the theta_psi rescaling (RESEARCH Pitfall 4) — it is mandatory. Do NOT prepend a 0 to cumulative_trapz output (out[0] is already 0, RESEARCH anti-pattern). Do NOT use simpsons_weights for the CDF (use cumulative_trapz). All three fns must never panic on bad input.

    Add an inline `#[cfg(test)] mod tests` covering the behaviors above: a `truncated_gaussian(argvals, mu)` helper, `normalize_density_integral_to_one`, `lqd_uniform_is_zero`, `lqd_transform_finite`, `round_trip_lqd_density_within_tolerance`, `inverse_lqd_normalized_nonneg`, `error_negative_density`, `error_length_mismatch`, `error_non_monotone_grid`. Use the RESEARCH §Code Examples round-trip test verbatim as the basis. Seed nothing (deterministic analytic densities).
