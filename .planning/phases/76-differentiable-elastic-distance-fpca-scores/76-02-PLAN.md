<objective>
Deliver DIF-03: a fully-differentiable, generic-over-`Scalar` FPCA score projection that maps a curve onto trained FPCA loadings → scores, living ALONGSIDE the existing f64 `FpcaResult::project`.

At `Dual` it yields exact forward-mode gradients of each FPC score w.r.t. the input curve's sample values; at `f64` it reproduces the existing FPCA scores. Because the projection is LINEAR in the curve values, the gradient of `score_k` w.r.t. `curve[j]` is exactly the constant `rotation[(j,k)] * weights[j]` — the strongest possible AD check (assert to <=1e-12, tighter than FD).

Purpose: FPC scores can now flow into any differentiable objective while `FpcaResult` fields (rotation/mean/weights — products of the f64 SVD) and `FpcaResult::project` stay byte-for-byte unchanged (protects R + WASM bindings + 28 examples).

Output: `project_scores_generic<S: Scalar>` free function + a thin `FpcaResult::project_generic` method wrapper + inline tests in `regression.rs`; minimal re-export in `lib.rs`; all gates green.
</objective>
