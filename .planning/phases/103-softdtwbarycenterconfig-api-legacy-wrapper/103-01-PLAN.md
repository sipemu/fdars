<objective>
Expose the Phase 101/102 soft-DTW barycenter optimizer through a public
`SoftDtwBarycenterConfig` (StlConfig-style sealed config) and a new config-taking
entry point `soft_dtw_barycenter_with_config`, while preserving the existing
`soft_dtw_barycenter(data, gamma, max_iter, tol)` signature as a behavior-compatible
wrapper. New items are additively re-exported at crate root + prelude with a running
doctest. Implements SDTW-03.

Purpose: Give external callers a configurable, forward-compatible entry point to the
multi-restart optimizer without breaking a single existing call site, example, or binding.
Output: New config struct, new entry point, PartialEq on the result type, and three
additive re-export lines — all non-breaking.
</objective>
