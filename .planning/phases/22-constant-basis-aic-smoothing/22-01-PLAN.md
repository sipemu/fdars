<objective>
Deliver T-01 — two additive, non-breaking capabilities that wrap existing fdars infrastructure:

1. A named `constant_basis(t: &[f64]) -> Vec<f64>` constructor in `basis/` returning a column-major m×1 all-ones matrix (the intercept column for a regression design matrix), mirroring the `Vec<f64>`-returning convention of `bspline_basis`/`fourier_basis` (per D — constant/intercept basis decision).

2. An **AIC criterion** in automatic smoothing-parameter selection: (a) an `Aic` variant on `CvCriterion` + its implementation in `optim_bandwidth`, reusing the hat-matrix trace already computed for GCV (`AIC = n·ln(RSS/n) + 2·tr(S)`); and (b) an AIC-based λ selector for basis smoothing alongside `smooth_basis_gcv` that searches the same log-λ grid but minimizes AIC.

Purpose: Closes the top-ranked (score 5.00) R-parity table-stakes gap — `fda`/`fda.usc` constant basis + `akaike_information_criterion` smoothing — with the highest value-per-effort ratio in the v0.20.0 backlog.

Output: New `basis/constant.rs`; extended `smoothing.rs` (`CvCriterion::Aic`, `aic_smoother`) and `smooth_basis.rs` (AIC λ selector); crate-root re-exports; inline `#[cfg(test)]` tests.
</objective>
