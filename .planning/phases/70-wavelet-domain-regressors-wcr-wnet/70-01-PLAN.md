## Recovery-test design (MANDATORY — from project memory; do NOT get this wrong)

The `wcr` β(t)-recovery tests (Tasks 1 and 2) MUST build a SPANNING, FULL-RANK predictor design from pseudo-random curves with `n ≫ m`. NEVER use phase-shifted single-frequency sinusoids — they span only a 2-D subspace, making recovery tests silently pass/fail. NEVER loosen the tolerance to make a rank-deficient design pass — fix the design.

Suggested construction (mirrors the DWT module's own `pseudo_random` LCG test helper at `wavelet/mod.rs` lines 557-570, so no new dependency):
- Build `n` (e.g. 80-120) pseudo-random curves at `m` (e.g. 32-48) grid points via a deterministic LCG seeded per curve (`seed + i`). This yields a full-rank n×m design.
- Choose a known coefficient-space β (or a known time-domain β(t)); generate `y = intercept + X_design · β_coeff + small noise` where `X_design` is the wavelet-coefficient design of the curves (so the true relationship lives in coefficient space and β(t) is its inverse-DWT image).
- Fit `wcr` with enough components (ncomp near `min(n, P)`) and assert recovered β(t) matches the injected β(t) within a fixed relative L2 tolerance.
- Use the same spanning design for both the PCR and PLS tests.
</critical_test_design>
