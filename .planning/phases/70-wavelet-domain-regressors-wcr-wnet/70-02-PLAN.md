<objective>
Deliver the `wnet` wavelet-domain elastic-net scalar-on-function regressor (WAV-04): transform curves → wavelet coefficients (via Plan 01's shared `curves_to_coeff_design`), fit L1+L2 elastic-net via a NEW thin per-coefficient coordinate-descent adapter with cross-validated λ, then map the fitted sparse coefficient-space weights back to β(t) via the shared `coeff_weights_to_beta_t` (inverse DWT).

Purpose: `wnet` is the sparse/elastic-net half of the wavelet-domain regressor pair (GAP-07). A sparse wavelet basis is exactly where L1 shrinkage shines — localized signal concentrates in a few coefficients. Per locked decisions, `wnet` uses a NEW per-coefficient CD adapter reusing `additive.rs`'s soft-threshold PATTERN (group-lasso ≠ per-coefficient elastic-net), NOT `variable_selection` directly.
Output: `WnetConfig`/`WnetResult`/`wnet` + the CD adapter + CV-λ helper added to `fdars-core/src/wavelet/regression.rs`; inline-tested for sparse recovery, deterministic CV-λ, β(t) recovery on SNR data, and validation.
