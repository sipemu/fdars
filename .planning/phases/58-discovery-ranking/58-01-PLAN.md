# Phase 58 Plan — Discovery & Ranking

Build `src/shapelet/discovery.rs` on top of Phase 57's `shapelet_distance` /
`Shapelet` / `z_normalize_window`. Additive/non-breaking, no new dependency, no
crate version bump, no crate-root re-exports (Phase 60).

## Task 1 — Config & result types (SHP-03/04/05 scaffolding)
- `enum QualityMeasure { InfoGain, FStatistic }` — `#[non_exhaustive]`, Default `InfoGain`, Debug/Clone/Copy/PartialEq/Eq, serde-gated.
- `struct ShapeletDiscoveryConfig { min_length, max_length, max_candidates: Option<usize>, max_shapelets, quality, seed }` — Debug/Clone/PartialEq, serde-gated. `Default`: `min_length=3`, `max_length=0` (sentinel → resolved to ncols at fit), `max_candidates=Some(10_000)`, `max_shapelets=0` (sentinel → `min(10*n, 1000)` at fit), `quality=InfoGain`, `seed=0`.
- `struct ShapeletSet { shapelets: Vec<Shapelet>, quality: QualityMeasure }` — Debug/Clone/PartialEq, serde-gated, `#[non_exhaustive]`; accessors `shapelets()`, `len()`, `is_empty()`, `quality()`.

## Task 2 — Quality measures (SHP-04)
- `fn information_gain(orderline: &[(f64, usize)], n_classes) -> f64`: sort (dist,label) by `total_cmp`; parent Shannon entropy; scan midpoints between consecutive *distinct* distances; `IG = H(all) − (|L|/n·H(L) + |R|/n·H(R))`; return max IG. O(n log n).
- `fn f_statistic_1d(distances: &[f64], labels: &[usize]) -> f64`: one-way ANOVA F of the 1-D distance vector grouped by label. Documented as the scalar analogue of `function_on_scalar::integrated_f_statistic`. `ms_within ≤ 1e-15 → 0.0`.
- `fn score_candidate(distances, labels, n_classes, quality) -> f64` dispatch.

## Task 3 — Candidate generation (SHP-03)
- Enumerate `(series_idx, start, length)` for `length ∈ [min_length, max_length]`, `start ∈ [0, ncols-length]`. Exhaustive count = `n · Σ (ncols−L+1)`.
- If `max_candidates = Some(m)` and exhaustive count > m: deterministically random-sample m distinct triples via `seed_for_thread(seed, 0)` (index-shuffle-free reservoir/rejection with a sorted dedup for stability). Else exhaustive. Sort the chosen triples by `(series_idx, start, length)` so the candidate order is seed-fixed and deterministic before scoring.
- Each triple → `Shapelet::from_source`.

## Task 4 — fit driver + selection & pruning (SHP-05)
- `discover_shapelets(data, labels, config) -> Result<ShapeletSet, FdarError>` `#[must_use]`.
  - Validate: `labels.len()==nrows`; `≥2` distinct classes; `min_length ≥ 1`; `min_length ≤ max_length ≤ ncols`; `max_shapelets ≥ 1` (after sentinel resolution). Errors → `InvalidDimension`/`InvalidParameter`.
  - Resolve sentinels; build candidate list (Task 3).
  - Pre-extract each series row via `row_to_buf` into a `Vec<Vec<f64>>` (rows=curves).
  - Score candidates in parallel with `iter_maybe_parallel!` over candidate indices: for each, compute the orderline (`shapelet_distance` with `best_so_far=INFINITY` per series) → quality. Candidate set fixed before scoring → sequential==parallel, deterministic.
  - Sort scored candidates by quality desc, tie-break `(series_idx,start,length)` using `f64::total_cmp` on quality.
  - Greedy select with self-similarity pruning: when selecting from series i spanning `[start,start+length)`, discard not-yet-selected same-series candidates whose range overlaps. Stop at `max_shapelets`. Set each `Shapelet.quality`.
  - Return `ShapeletSet`.
