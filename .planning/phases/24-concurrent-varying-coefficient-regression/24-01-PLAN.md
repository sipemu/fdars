<objective>
Implement dense functional concurrent (varying-coefficient) regression as a new public entry point `concurrent_regression` in `fdars-core/src/concurrent_regression.rs`, re-exported at the crate root, fulfilling REG-01.

The model is y_i(t) = β₀(t) + Σₖ βₖ(t)·xₖᵢ(t) + εᵢ(t) on a dense shared grid of m points. Estimation is the fdaconcur two-step convention: (1) pointwise OLS at each grid column via `smoothing::solve_gaussian_pub`; (2) local-linear kernel smoothing of the resulting β sequences via `smoothing::local_linear`, where kernel bandwidth is the roughness knob. Result carries `{ beta_curve, intercept, fitted, residuals, argvals }`.

Purpose: closes the P1 table-stakes REG-01 gap (dense concurrent regression) against the R ecosystem, reuse-first with zero new dependencies and zero changes to existing public signatures.
Output: new module `concurrent_regression.rs` (fn + result struct + inline tests) and two additive lines in `lib.rs`.
</objective>
