<objective>
Wave 3 expansion: the primary PERF-01 compute win — OPT-E restructures `irreg_fdata::cov_irreg` (the hot inner path of `face_covariance`, PROF-01 hot-path #1 at 984ms @ n200_m30) to precompute per-observation Gaussian kernel-weight tables `w_s` and `w_t` once, before the `(si, ti)` grid loop, replacing the redundant per-cell `exp()` evaluations with table lookups. The `w1 = kernel((obs_t[j1]-s)/bw)` factor depends on the grid column `s` but not the row `t` (and vice-versa for `w2`), so across the ns x nt grid each `exp()` is currently recomputed ns (or nt) times. Factoring the tables out is algebraically exact and cuts `exp()` calls by ~98%.

Purpose: this is the highest wall-time target with a safe behavior-preserving win. MEDIUM risk (internal loop restructure), so it lands after the OPT-A tracer proves the harness, guarded by a golden test authored first.
Output: restructured `cov_irreg`/`accumulate_cov_at_point` in `smoothing.rs`; `golden_face_covariance` test; a face_covariance before/after criterion cell + PERF-RESULTS.md row.
