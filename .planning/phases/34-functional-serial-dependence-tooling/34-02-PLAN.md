    - On a trended non-stationary series X_i(t) = i*t + GP_sample (seeded) the observed statistic is large and the p-value is small (rejects at 0.05).

  </behavior>
  <action>
Add `stationarity_test(data: &FdMatrix, argvals: &[f64], n_perm: usize, seed: u64) -> Result<StationarityResult, FdarError>`: call `validate_fts_input`; if `n_perm == 0` return `FdarError::InvalidParameter { parameter: "n_perm", message: "must be >= 1".to_string() }`. Compute `xbar` via the plan-34-01 mean-curve helper, center the curves, and define a private `stationarity_statistic(centered_rows_in_order, m, weights) -> f64` computing T per the pinned formula: partial sums `S_k[j] = Σ_{i<k} centered[i][j]`, then `T = (1/n²) Σ_{k=1}^{n} Σ_j S_k[j]² * weights[j]`. Compute observed T on the natural row order.

Permutation loop: `StdRng::seed_from_u64(seed)` (single shared seed), maintain a row-index permutation vector, Fisher-Yates shuffle it each of n_perm iterations (per 34-PATTERNS.md shuffle_indices), recompute T over the permuted row order, count `n_ge` where `perm_T >= observed_T`; `p_value = (n_ge as f64 + 1.0) / (n_perm as f64 + 1.0)`. Return `StationarityResult { statistic: observed_T, p_value, n_perm }`.

Register `stationarity_test` and `StationarityResult` in the `fts/mod.rs` `pub use` block and the crate-root `pub use fts::{...}` block in `src/lib.rs`.

Add a rustdoc DIVERGENCE / ASSUMED note on `stationarity_test`: the ftsa `T_stationary` statistic (Horváth-Kokoszka-Rice 2014) includes a long-run-variance normalization that is not pinned from documentation alone; this implementation uses the unnormalized KPSS-style partial-sum statistic with a pure seeded-permutation p-value (valid regardless of the normalization constant), documented as a known divergence and future-precision item.

Add inline tests `stat_test_stationary` (does not reject) and `stat_test_nonstationary` (rejects on i*t trend), both seeded; and `stat_test_invalid` for `n_perm == 0` and empty-matrix error paths.
