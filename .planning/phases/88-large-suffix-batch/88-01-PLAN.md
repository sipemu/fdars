<objective>
Consolidate the large remaining batch of public lone-`_1d`/`_2d` suffix functions across `fdars-core` onto `Dim`-dispatched signatures (Cat 1/2/3) or plain renames (genuinely-1D-only functions), and migrate every external call site (28 examples, tests, benches, doctests) to the new surface. This is NAME-04 — the terminal, highest-blast-radius naming-unification pass of milestone v0.42.0.

Purpose: Finish the crate-wide API-shape unification so v0.42.0 ships a single Dim-dispatched signature per family. This is an API-shape-only change: every consolidated signature routes to a byte-identical body (existing test suite is the numeric non-regression proof).
Output: All in-scope `_1d`/`_2d` public names removed/consolidated; new dispatcher + plain-rename names in place; all re-exports and external call sites updated; full gate set green.
</objective>

<user_story>
**As a** downstream consumer of `fdars-core`, **I want to** call every depth/metric/fdata/basis/regression function through one clear signature (a `Dim`-dispatched entry or a plain name), **so that** I no longer have to guess between a lone `_1d` symbol and its dispatcher and the v0.42.0 public surface is internally consistent.
</user_story>

## Locked user decisions governing this plan (NON-NEGOTIABLE)

- **Plain rename (drop `_1d`, NO `dim` param)** for the genuinely-1D-only functions: `fdata_to_pc_1d`→`fdata_to_pc`, `fdata_to_pls_1d`→`fdata_to_pls`, `select_basis_auto_1d`→`select_basis_auto`, `fourier_fit_1d`→`fourier_fit`, `pspline_fit_1d`→`pspline_fit`. Global symbol rename across the WHOLE crate (definition + all internal callers + external callers + re-exports + lib.rs doctest). NO dispatcher, NO `pub(crate)`.
- **SIMPLIFIED CONSOLIDATION MECHANIC (minimizes diff, from RESEARCH Pitfall 1):** For Cat 1/2/3 do NOT rename bodies to `_impl`. Flip visibility only: `pub fn X_1d(` → `pub(crate) fn X_1d(` (body byte-identical; `dispatch.rs` and all internal callers keep working unchanged because `pub(crate)` is crate-visible).
- `_seeded` variants (`random_projection_1d_seeded`, `random_tukey_1d_seeded`, `rpd_depth_1d_seeded`) STAY as-is (public).
- The 3 lone `_2d` (`fosr_2d`, `predict_fosr_2d`, `simpsons_weights_2d`) STAY as-is.
- The Cat-5 exclusions stay: `FdCurveSet::from_1d`, `fdata_to_basis_1d`, `basis_to_fdata_1d` (R-interop `i32` shims — KEEP in `basis/mod.rs` and `lib.rs`).

</decisions>
