# Phase 56 — Plan 56-01: Kernel-k-means Clustering (GAK-07/08)

**Status:** in-progress
**Phase:** 56 — Kernel-k-means Clustering (final phase of v0.32.0)
**Depends on:** Phase 54 (GAK kernel), Phase 55 (`gak_gram_train`/`gak_gram_predict`)

## Goal

Deliver kernel-k-means clustering of curve sets through the GAK kernel plus
out-of-sample `predict`, operating purely on the GAK Gram matrix (no centroid
curve). New top-level `fdars-core/src/kernel_kmeans.rs`, re-exported at crate root.
Additive/non-breaking; no new dependency; no crate-version bump.

## Tasks

### T1 — Config + Result types (GAK-07)
- `KernelKmeansConfig { n_clusters, n_init, max_iter, tol, seed, gak: GakConfig }`
  — Debug/Clone/PartialEq, serde-gated, `Default` (n_init=10, max_iter=300,
  tol=1e-4, n_clusters=2, seed=0).
- `KernelKmeansResult { cluster: Vec<usize>, inertia: f64, iter: usize,
  converged: bool, n_init_best: usize }` + internal state for predict
  (`train: GakGramTrain`, `within: Vec<f64>`, `sizes: Vec<usize>`) —
  Debug/Clone/PartialEq, serde-gated, `#[non_exhaustive]`. **NO centroid field.**

### T2 — `kernel_kmeans_fd` fit (GAK-07)
- Validate: n_clusters≥1, n_clusters≤n, n_init≥1, non-empty data.
- Build GAK Gram ONCE via `gak_gram_train(data, &config.gak)`.
- `n_init` random-partition restarts, each seeded `seed_from_u64(seed + restart)`.
- Per iteration: precompute `within_k = (1/|C_k|²)·ΣΣ K[j,l]` once per cluster;
  assign each point to argmin `d²(i,k) = K[i,i] − (2/|C_k|)·Σ_{j∈C_k}K[i,j] + within_k`.
- Empty-cluster recovery: reseed with the point of max d² to its cluster (never panic).
- Convergence when labels stop changing or Δinertia < tol; cap at max_iter.
- Keep lowest total-inertia restart. Store fitted `GakGramTrain` + final `within`
  + cluster sizes for predict.

### T3 — `KernelKmeansResult::predict` (GAK-08)
- `Kcross = gak_gram_predict(&self.train, new_data)` (n_test × n_train, normalized).
- Assign each new curve to argmin `d²(t,k) = 1 − (2/|C_k|)·Σ_{j∈C_k}Kcross[t,j] + within_k`
  using the FITTED `within` and cluster sizes. Reuses fit σ/normalization.

### T4 — Wiring
- `pub mod kernel_kmeans;` in `src/lib.rs`; re-export `kernel_kmeans_fd`,
  `KernelKmeansConfig`, `KernelKmeansResult` at crate root.

### T5 — Tests (inline `#[cfg(test)] mod tests`)
recovers_groups, deterministic, empty_cluster_recovery, n_init, predict,
validation, no_centroid + doctest on `kernel_kmeans_fd`.

## Gates

## Success criteria (ROADMAP)
1. Two well-separated groups → purity 1.0, no centroid field.
2. n_init restarts (best inertia), empty-cluster recovery no-panic, Gram once.
3. Deterministic per-restart seeding → identical labels same seed.
4. Out-of-sample predict reuses fit kernel/normalization, routes correctly.
