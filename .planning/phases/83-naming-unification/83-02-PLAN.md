<objective>
Collapse `deriv_1d` + `deriv_2d` into a single public dispatcher `deriv` via the user-approved GRID-ENUM design (per D: AUD-17 + the grid-enum decision in 83-CONTEXT.md). The 1D/2D forms have incompatible signatures (2D needs `argvals_s`/`argvals_t`/`m1`/`m2` and returns `Option<Deriv2DResult>`; 1D needs `nderiv` and returns `FdMatrix`), so a `name(..., Dim)` last-arg pattern does NOT fit — instead the dimension-specific grid + params ride inside an input enum and the two return shapes unify in an output enum.

Purpose: Remove the `_1d`/`_2d` suffix sprawl on deriv while preserving byte-identical numerics — the dispatcher just routes to the existing computation bodies (kept as private helpers).
Output: New public `enum DerivDomain`, new public `enum DerivResult`, new `pub fn deriv`, two private impl helpers holding the original bodies, all callers/tests/doctests/examples migrated. Whole-crate gates green.
</objective>
