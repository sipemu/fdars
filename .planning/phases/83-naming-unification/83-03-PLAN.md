<objective>
Collapse `lp_self_1d`/`lp_cross_1d`/`lp_self_2d`/`lp_cross_2d` into two public dispatchers `lp_self` and `lp_cross` via the user-approved GRID-ENUM design (per D: AUD-18 + the grid-enum decision in 83-CONTEXT.md). The 1D form takes one `argvals`; the 2D form takes `argvals_s`/`argvals_t` — incompatible signatures — so the dimension-specific grid rides inside an input enum. Both arities already return `FdMatrix`, so no output enum is needed.

Purpose: Remove the `_1d`/`_2d` suffix sprawl on the lp metric family while preserving byte-identical numerics — the dispatchers just route to the existing computation bodies (kept as private helpers).
Output: New public `enum LpDomain`, new `pub fn lp_self`, new `pub fn lp_cross`, four private impl helpers holding the original bodies, all callers/tests/doctests/example migrated. Whole-crate gates green. This is the final plan of the phase — its green gates ARE the phase-completion proof (all 5 AUD items + all 28 examples/doctests compile).
</objective>
