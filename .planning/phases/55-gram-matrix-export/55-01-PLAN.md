# Phase 55 — Plan 55-01: Gram-Matrix Export (GAK-05/06)

**Phase:** 55 — Gram-Matrix Export
**Plan:** 55-01
**Depends on:** Phase 54 (GAK kernel core — `metric/gak.rs`)
**Scope:** Additive, non-breaking. No crate version bump. No new dependency.

## Goal

Deliver a split train/predict GAK Gram-matrix export API so users can drive an
EXTERNAL precomputed-kernel SVM (`SVC(kernel='precomputed')` convention). Makes
the cross-normalization bug (Pitfall 8) structurally impossible by carrying the
training self-kernels in the result struct.

## Task Breakdown

### T1 — `GakGramTrain` result struct (→ GAK-05)
- `pub struct GakGramTrain { pub gram: FdMatrix, pub(crate) log_self: Vec<f64>, pub sigma: f64 }`.
- Derive `Debug, Clone, PartialEq`; serde-gated `cfg_attr`; `#[non_exhaustive]`.
- Add a `&self` read accessor `log_self()` for the `pub(crate)` diagonals (no public exposure of the field).

### T2 — `gak_gram_train` (→ GAK-05)
- `pub fn gak_gram_train(data: &FdMatrix, config: &GakConfig) -> Result<GakGramTrain, FdarError>`, `#[must_use]`.
- Resolve σ (`sigma_gak` when `config.sigma == None`); validate σ>0 & non-empty (mirror `gak_gram_matrix`).
- Factor a shared helper `build_train_gram` producing `(FdMatrix, Vec<f64> diag_log, f64 sigma)` and have BOTH `gak_gram_matrix` and `gak_gram_train` call it — `gak_gram_matrix` signature/behavior unchanged.
- Store `log_self[i] = loggak(x_i,x_i,σ)` and resolved `sigma`.

### T3 — `gak_gram_predict` (→ GAK-06)
- `pub fn gak_gram_predict(train: &GakGramTrain, new_data: &FdMatrix) -> Result<FdMatrix, FdarError>`, `#[must_use]`.
- Validate: non-empty test; equal #cols (grid width) between train.gram (n_train) and new_data; σ>0 already guaranteed by train.
- Output n_test × n_train. Entry `(t,j) = exp(loggak(x_test_t,x_train_j,σ) - 0.5*(loggak(x_test_t,x_test_t,σ) + train.log_self[j]))` using STORED `train.sigma` + `train.log_self`.
- Compute test self-log-kernels once (O(n_test)). Reuse `normalize_log`.
- Parallelize cross-matrix rows via `iter_maybe_parallel!` (deterministic; seq==par).
- ASSERT orientation in a test.

### T4 — Re-exports
- `metric/mod.rs:141` extend `pub use gak::{...}` with `gak_gram_train, gak_gram_predict, GakGramTrain`.
- `lib.rs` metric re-export block: add same three.

### T5 — Tests (inline in `gak.rs mod tests`)
- `test_gram_train_shape_psd`, `test_gram_predict_shape` (n_test≠n_train), `test_gram_predict_normalized`, `test_gram_predict_reproduces_train`, `test_gram_predict_sigma_consistency`.
- Validation error tests (empty test, grid-width mismatch).
- Doctest on `gak_gram_train`/`gak_gram_predict`: train + predict → commented sklearn `SVC(kernel='precomputed')` handoff.
