<objective>
Surface the already-implemented, already-correct banded Sakoe-Chiba DP path through the high-level elastic alignment API so previously-infeasible large grids (N=500, M=200) become tractable — while leaving the exact unbanded path and every existing caller untouched (PERF-03).

This is API surfacing, NOT a new algorithm. The banded implementations (`karcher_mean_impl` with a non-zero `band_frac`, `self_distance_matrix_impl` / `cross_distance_matrix_impl` with `Some(band)`) and the `band_radius` helper already exist and are tested. This plan adds three thin `*_with_band(…, band_frac: Option<f64>)` delegation wrappers, wires their re-exports (plus the existing `_banded` variants) to the crate root, adds equivalence tests, and adds a feasibility bench.

Purpose: Users can opt into the 4-6x banded path from the crate root without knowing about the `alignment` submodule or the `_banded` variants, per the LOCKED opt-in / non-breaking decision (D — CONTEXT.md "API shape: opt-in, non-breaking").
Output: Three new public wrapper functions, expanded crate-root re-exports, five equivalence tests, one feasibility bench group.
</objective>
