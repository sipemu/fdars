## Notes / risk
- kNN training predictions use LOO (`knn_predict_loo`); `predict_from_scores` uses plain kNN, so
  `predict(train)` != fit-time predictions for kNN. Consistency test therefore uses **LDA**, where
  `predict_from_scores` reproduces the fit-time discriminant on the same projected scores.
- Binary vs multiclass in `predict_from_scores`: binary returns P(Y=1) → threshold 0.5; multiclass
  returns class index as f64. Handle both.
- Version stays **0.32.0** (milestone bump handled by orchestrator).
