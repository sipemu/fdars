# Phase 59 · Plan 59-01 — Shapelet Transform (SHP-06)

**Milestone:** v0.33.0
**Requirement:** SHP-06
**Depends on:** Phase 57 (`shapelet_distance`, `Shapelet`), Phase 58 (`ShapeletSet`, `discover_shapelets`, `ShapeletDiscoveryConfig`)
**Scope:** Additive, non-breaking. New file `src/shapelet/transform.rs`, exposed via `src/shapelet/mod.rs`. No crate-root re-exports (Phase 60). No version bump. No new dependency.

## Goal (from ROADMAP success criteria)
1. `shapelet_transform_fit(data, y, config)` → discover shapelets + `n×K` `FdMatrix` where `X[i,j] = sdist(shapelet_j, curve_i)`, plus the stored `ShapeletSet`.
2. `shapelet_transform(fit, new_data)` (via `ShapeletTransformFit::transform`) → `n_new×K` out-of-sample features using the exact stored, already-z-normalized shapelets — no re-discovery, no re-normalization.
3. Transform consistency: re-transforming training data reproduces fit-time distances within 1e-12; two `transform(train)` calls bit-identical.
4. All outputs finite; a curve shorter than the longest shapelet → `Err(FdarError::InvalidDimension)`.

## Design decisions (from 59-CONTEXT.md — authoritative)
- `pub fn shapelet_transform(shapelets: &ShapeletSet, data: &FdMatrix) -> Result<FdMatrix, FdarError>` (`#[must_use]`), n×K, `X[(i,j)] = shapelet_distance(&shapelets.shapelets()[j].values, row_i, f64::INFINITY).0`. Shapelet `values` already z-normalized — reuse directly. Parallelize the ROW loop with `iter_maybe_parallel!` (order-independent → deterministic). `row_to_buf` each series row once.
- `pub struct ShapeletTransformFit { shapelets: ShapeletSet, features: FdMatrix }` — `Debug, Clone, PartialEq`, serde-gated, `#[non_exhaustive]`. Accessors `shapelets() -> &ShapeletSet`, `features() -> &FdMatrix`. Method `transform(&self, new_data) -> Result<FdMatrix, FdarError>` = `shapelet_transform(self.shapelets(), new_data)`.
- `pub fn shapelet_transform_fit(data, labels, config) -> Result<ShapeletTransformFit, FdarError>` (`#[must_use]`): `discover_shapelets` then `shapelet_transform` on training data; store both.
- Validation: empty `ShapeletSet` (K=0) → `FdarError::InvalidParameter`. Series shorter than a shapelet → `FdarError::InvalidDimension` (propagated from Phase 57). All outputs finite (Phase 57 z-norm guard).
- Feature columns are shapelet distances, NOT evaluation points — documented.

## Tasks
- **T1** Create `src/shapelet/transform.rs` module doc + imports (`FdMatrix`, `FdarError`, `shapelet_distance`, `ShapeletSet`, `discover_shapelets`, `ShapeletDiscoveryConfig`, `iter_maybe_parallel`).
- **T2** Implement `shapelet_transform`: K = `shapelets.len()`; K==0 → `InvalidParameter`. Parallel over rows: `row_to_buf` into a per-row buffer, compute K distances (propagate `?` from `shapelet_distance` — short-series surfaces as `InvalidDimension`). Assemble n×K column-major `FdMatrix`. Rayon closures return `Result`; collect `Vec<Result<...>>` then bubble the first error (deterministic since each row is independent).
- **T3** Implement `ShapeletTransformFit` struct + accessors + `transform`.
- **T4** Implement `shapelet_transform_fit` (discover → transform train → store). Doctest here (fit → transform new data).
- **T5** Wire `pub mod transform;` + `pub use transform::{shapelet_transform, shapelet_transform_fit, ShapeletTransformFit};` into `mod.rs`; update module-level doc (transform step now shipped).
- **T6** Inline `#[cfg(test)] mod tests`: all 7 tests from spec.

## Tests (SHP-06 acceptance hooks)
- `test_transform_fit_shape` — fit → features n×K, K == discovered, all finite.
- `test_transform_out_of_sample_shape` — `fit.transform(new_data)` → n_new×K, n_new ≠ n_train (catches transpose).
- `test_transform_consistency` — `fit.transform(&train)` reproduces `fit.features()` within 1e-12 (KEY gate).
- `test_transform_values_are_sdist` — tiny hand-checked case; X[i,j] == `shapelet_distance(shapelet_j, curve_i).0` exactly.
- `test_transform_short_series_error` — new series shorter than longest shapelet → `Err(InvalidDimension)`.
- `test_transform_empty_set_error` — K=0 → `Err(InvalidParameter)`.
- Doctest on `shapelet_transform_fit`.
