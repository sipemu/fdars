## Task Breakdown

### T1 — Module skeleton (SHP-01/02 scaffolding)
- Create `src/shapelet/mod.rs` with `//!` header describing the shapelet domain module + `pub mod distance;` + `pub use distance::{Shapelet, shapelet_distance, z_normalize_window, z_normalize_into};`.
- Add `pub mod shapelet;` to `src/lib.rs` (alphabetical, near other domain modules). NO crate-root `pub use shapelet::{...}`.

### T2 — z_normalize (SHP-01)
- `z_normalize_into(src: &[f64], dst: &mut [f64])`: two-pass mean then population std (ddof=0). Constant-window guard: `std <= 1e-12` → write all zeros. Never NaN/Inf. `debug_assert_eq!(src.len(), dst.len())`.
- `z_normalize_window(slice: &[f64]) -> Vec<f64>`: allocating wrapper over `_into`.
- Doc the ddof=0 choice (pyts convention; sktime may use ddof=1 — divergence noted).

### T3 — Shapelet struct (SHP-02 support)
- `pub struct Shapelet { pub values: Vec<f64>, pub series_idx: usize, pub start: usize, pub length: usize, pub quality: f64 }`.
- Derive `Debug, Clone, PartialEq`; serde-gated. `#[non_exhaustive]` per convention.
- `len()` accessor + `is_empty()`. `from_source(series: &[f64], series_idx, start, length) -> Result<Shapelet, FdarError>` constructor that z-normalizes the source window and records provenance (quality 0.0; set in Phase 58). Range check → `InvalidDimension`.

### T4 — shapelet_distance / sdist (SHP-02)
- `shapelet_distance(shapelet_z: &[f64], series: &[f64], best_so_far: f64) -> Result<(f64, usize), FdarError>`.
- Guard: `shapelet_z.len() > series.len()` or empty shapelet → `InvalidDimension`.
- Slide length-L window over series; z-normalize each window on the fly into a reused buffer; accumulate squared Euclidean vs shapelet_z; EARLY-ABANDON: break inner element loop when running squared sum > `best_so_far_sq` (compare in squared space). Track running best squared distance across windows; feed it as the abandon bound. Strict `<` update for first-min-offset determinism. Return `(sqrt(best_sq), best_offset)`. `best_so_far = INFINITY` disables abandon.
- `#[must_use]`. Plain Euclidean — NOT weighted/Simpson.
