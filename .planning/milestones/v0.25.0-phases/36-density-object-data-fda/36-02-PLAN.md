    1. Validate at entry (36-PATTERNS.md gates): `let (n, m) = density_matrix.shape();` reject n == 0 (InvalidDimension, empty sample), reject `argvals.len() != m` (InvalidDimension), reject argvals not strictly increasing (InvalidParameter). Accumulate the weighted average into `q_bar[k] += weights[i] * Q_i(t_grid[k])`.
