  </behavior>
  <action>
    Add `VarSelectPenalty` enum with `#[derive(Debug, Clone, Copy, PartialEq)]` + `#[non_exhaustive]` + `#[cfg_attr(feature = "serde", ...)]` (copy the GlmFamily attribute ordering, 31-PATTERNS.md section 2). Implement ONLY `GroupLasso` this phase; the coordinate-descent path returns FdarError::InvalidParameter (or documents fallback to GroupLasso) for MCP/SCAD — document MCP/SCAD as future work in rustdoc.

    Add `VarSelectConfig` (ncomp=3 default, penalty=GroupLasso, lambda=0.0 => CV-select, max_iter=100, epsilon=1e-5, lambda_n_grid=20) and `VarSelectResult` (active_predictors (len P bool), coefficients (P x K_p), fitted_values, residuals, intercept, lambda, r_squared, iterations, converged, fpcas: Vec<FpcaResult>) with the standard derive/serde/non_exhaustive stack; `fpcas` mirrors MultiFregreLmResult (31-PATTERNS.md section 3).

    Implement `variable_selection(predictors: &[&FdMatrix], y, argvals_list: &[&[f64]], scalar_covariates, config)` with the `#[must_use = ...]` string. Validate: non-empty predictors; predictors.len()==argvals_list.len(); every predictors[p].nrows()==y.len() (else FdarError::InvalidDimension). Per predictor run fdata_to_pc_1d to get score group ξ^p (n×K_p). Build design X = [1 | ξ^0 | … | ξ^{P-1} | Z]. Group-lasso coordinate descent (31-RESEARCH.md Pattern 4): per group g, β_g_ols = (X_g'X_g)^{-1} X_g'(partial residual) via `crate::linalg::cholesky_solve` (FdarError::ComputationFailed on singular), then β_g = β_g_ols · max(0, 1 - λ√K_g / ||β_g_ols||); sweep groups until max coefficient delta < epsilon or max_iter. When config.lambda==0.0, CV-select λ over a grid from 0.01·λ_max to λ_max where λ_max = max_g ||X_g'y|| / √K_g (initialize at λ_max to avoid the immediate-zero stall, Pitfall 4). active_predictors[p] = ||β_group_p|| > epsilon threshold. r_squared via super::compute_r_squared.

    Document R-baseline divergence in rustdoc: refund's fosr.vs is function-on-scalar (functional response); fdars implements scalar-on-function variable selection (scalar response, functional predictors) — analogous group penalty, opposite regression direction.

    Extend the `mod.rs` and `lib.rs` re-export lists to add `variable_selection, VarSelectConfig, VarSelectResult, VarSelectPenalty`. Add the three varselect_* tests to the inline test module.
