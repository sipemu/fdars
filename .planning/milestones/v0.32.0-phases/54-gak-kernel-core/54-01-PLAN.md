# Phase 54 · Plan 54-01: GAK Kernel Core

**Status:** in-progress
**Requirements:** GAK-01, GAK-02, GAK-03, GAK-04
**File under test:** `fdars-core/src/metric/gak.rs` (new)

## Goal

Deliver a numerically-stable, PSD, normalized Global Alignment Kernel (TGAK, Cuturi
2011) between curves, plus an n×n Gram-matrix builder and a σ median-distance
bandwidth heuristic. Additive/non-breaking; new `src/metric/gak.rs` sibling to
`soft_dtw.rs`, re-exported through `metric/mod.rs` and the crate root.

## Tasks

1. **`logsumexp3(a,b,c)`** — `pub(crate)` soft-MAX helper with max-subtraction
   stabilization (mirrors `softmin3`'s structure but additive; NEG_INFINITY-safe).
2. **`loggak(x,y,sigma)`** — `pub(crate)` unnormalized log-domain forward DP over the
   full (n+1)×(m+1) alignment lattice using Cuturi's TGAK local kernel
   `log_local = -d²/(2σ²) - ln(2 - exp(-d²/(2σ²)))`; 2-row rolling buffer; returns
   `L[n][m]` in log space. Leaves the seam for Phase 55.
3. **`gak(x,y,sigma) -> f64`** — public normalized similarity
   `exp(loggak(x,y) - 0.5*(loggak(x,x)+loggak(y,y)))`; NEG_INFINITY→0 guard; result in [0,1].
4. **`GakConfig { sigma: Option<f64> }`** — Debug/Clone/PartialEq, serde-gated, Default (None).
5. **`gak_gram_matrix(data,&config) -> Result<FdMatrix,FdarError>`** — `#[must_use]`.
   Pre-collect rows; precompute n diagonal self-log-kernels once; compute upper
   triangle in parallel via `iter_maybe_parallel!`; normalize in log space; mirror
   `G[j][i]=G[i][j]` bit-exact; diagonal set to exactly 1.0. σ from config or heuristic.
6. **`sigma_gak(data) -> f64`** — median pairwise Euclidean distance between curves,
   with positive floor; matches tslearn-style median heuristic.
7. Wire `pub mod gak;` + re-exports into `metric/mod.rs`; re-export public surface at
   crate root `lib.rs` mirroring `soft_dtw`.
8. Inline `#[cfg(test)] mod tests` covering all PITFALLS verification hooks.

## Success criteria → tests

- **GAK-01 (log-domain, no underflow):** `test_gak_no_underflow` (m≥100) off-diagonal > 1e-10.
- **GAK-02 (normalization [0,1], unit diagonal, NaN-free):** `test_gak_normalized_range`.
- **GAK-03 (Gram symmetric-by-assignment + PSD + parallel-deterministic):**
  `test_gak_gram_symmetric` (bit-exact), `test_gak_gram_psd` (min eigenvalue ≥ −1e-8
  via nalgebra symmetric eigendecomposition), `test_gak_parallel_matches_sequential`.
- **GAK-04 (σ heuristic → healthy range):** `test_sigma_gak_healthy` (off-diagonal ≈0.05–0.95).
- **Reference correctness:** `test_gak_vs_reference` — hand-derived tiny case (documented DP by hand).
- Doctest on `gak`.
