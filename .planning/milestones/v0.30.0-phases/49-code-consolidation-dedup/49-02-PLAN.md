<objective>
Consolidate the SVD sign-fix (CONS-01, correctness-critical). The canonical rule — "for each
component k, make the largest-absolute-value entry positive" — currently lives in
`regression.rs::fix_svd_signs` (flips rotation AND scores in lockstep) and is MIRRORED inline in
`pace_fpca.rs:220` (flips eigenfunctions only — there is NO scores matrix at that point; scores are
BLUP-computed later). Per RESEARCH, pace_fpca CANNOT call fix_svd_signs directly (different arity).

Extract the shared sign-DECISION core (the max-abs-index + `<0.0` test) into ONE pub(crate) helper in
regression.rs (NOT distributions.rs — that module is numerical-tails only, per Open Question 2). Then
fix_svd_signs uses it to gate its two-matrix flip, and pace_fpca uses it to gate its single-matrix
flip. This kills the drift risk (the rule lives in one place) while preserving both call sites' exact
behavior. Bit-identical by construction (pure sign flips, same comparison rule).

Purpose: single home for the sign rule; zero behavior change.
Output: pub(crate) sign-decision core in regression.rs; pace_fpca migrated; SVD-sign goldens.
</objective>
