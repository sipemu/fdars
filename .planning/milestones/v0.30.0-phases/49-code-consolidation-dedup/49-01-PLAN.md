<objective>
TRACER SLICE (highest numerical risk): consolidate the χ²/regularized-incomplete-gamma
machinery — the two independent hand-rolled kernels in `inference/dist.rs` (SF-oriented) and
`spm/chi_squared.rs` (CDF-oriented) — into a new `src/distributions.rs` that shares only the
PRIMITIVES (`ln_gamma` + series + continued-fraction), while keeping two tail-specialized
wrappers so every existing call site stays BIT-IDENTICAL. This is the CONS-01 numerical target
and the phase tracer: it proves the golden-equivalence-then-migrate pattern end-to-end (scaffold
test → capture goldens from current code → create shared module → migrate call sites → assert
bit-identical under both feature configs) before the expansion plans build out from it.

Per RESEARCH: a single kernel CANNOT serve both families bit-identically (measured: catastrophic
far-tail divergence, χ²-SF at x=70.59 k=1 → 4.397e-17 vs 0.0). Therefore share primitives, split
tail policy — SF family keeps its Q-direct continued fraction (tiny=1e-300), CDF family keeps its
P-direct path (spm constants tiny=1e-30, eps=1e-14, -700 underflow guard).

Purpose: kill the two-kernel drift risk with one authoritative primitive home, zero behavior change.
Output: `src/distributions.rs` (pub(crate) primitives + 2 wrappers), migrated call sites, and the
`equivalence_phase49.rs` golden harness (Wave 0 scaffold shared by all later plans).
</objective>
