<objective>
Add a single new flat module `fdars-core/src/pace_fpca.rs` implementing the Yao–Müller–Wang (2005) PACE
sparse-FPCA estimator for sparse/irregularly-sampled functional data, and re-export it at the crate root.
One call `pace_fpca(&IrregFdata, &PaceFpcaConfig)` produces: a kernel-smoothed mean, a symmetric
eigendecomposition of the smoothed covariance surface (eigenvalues + eigenfunctions), per-curve
conditional-expectation (BLUP/PACE) FPC scores, fitted continuous trajectories, and pointwise confidence
bands. Reuse-first: the only genuinely new code is the BLUP score solve and the prediction-variance bands.

Purpose: closes FPCA-01, the last P1 table-stakes item — a PACE estimator for sparse curves that fdars
currently lacks. Additive/non-breaking; no new crate dependency.

Output: `fdars-core/src/pace_fpca.rs` (config struct, result struct, entry fn, inline tests) and two
re-export lines in `fdars-core/src/lib.rs`.
</objective>

  <behavior>
    - Given a curve i with observed times T_i and values Y_i, BLUP score ξ_ik = λ_k · φ_ik·v where v = Σ_yi⁻¹(Y_i − μ_i), Σ_yi = Φ_i diag(λ) Φ_iᵀ + σ² I on the n_i observed points; solved with ONE Cholesky per curve (not per component).
    - Fitted trajectory x̂_i(t) = μ(t) + Σ_k ξ_ik φ_k(t) on the work grid; row i of `fitted`.
    - Bands: Var(x̂_i(t)) = φ(t)ᵀ[diag(λ) − diag(λ)Φ_iᵀΣ_yi⁻¹Φ_i diag(λ)]φ(t), guarded `max(var, 0.0)`; `fitted_lower/upper = fitted ∓ z·sqrt(var)` with z = inverse-normal(1 − alpha/2) (z=1.96 for alpha=0.05).
    - Every `fitted[i,j]` lies within `[fitted_lower[i,j], fitted_upper[i,j]]` (z ≥ 0, var ≥ 0).
    - Deterministic: identical inputs → identical outputs (no RNG in the estimator itself).
  </behavior>
