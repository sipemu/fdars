# Phase 62 Plan 01: k-Shape Clustering & Predict (KSH-03/04)

**Phase:** 62 — k-Shape Clustering & Predict
**Milestone:** v0.34.0
**Requirements:** KSH-03 (k-Shape fit), KSH-04 (out-of-sample predict)
**Status:** in progress

## Goal

Deliver `kshape_fd` (iterative SBD-assignment + shape-extraction centroids, n_init
restarts, empty-cluster recovery, deterministic seeding) and `KShapeResult::predict`
in a new `src/kshape.rs`, built on Phase 61's `metric::sbd`. Additive/non-breaking,
no new dependency, no crate-version bump. Crate-root re-exports deferred to Phase 63.

## Tasks

### T1 — Module scaffold + config (KSH-03)
- New `src/kshape.rs`; `pub mod kshape;` in `lib.rs` (after `kernel_kmeans`).
- `KShapeConfig { n_clusters, n_init, max_iter, tol, seed }`: Debug/Clone/PartialEq,
  serde-gated, `#[non_exhaustive]`. Default: n_init=10, max_iter=100, tol=1e-6,
  seed=0, n_clusters=2. `KShapeConfig::new(n_clusters)`.

### T2 — Result type + accessors + predict (KSH-04)
- `KShapeResult { centroids: FdMatrix (k×m, z-normed), cluster, inertia, iter,
  converged, n_init_best }`: Debug/Clone/PartialEq, serde-gated, `#[non_exhaustive]`.
- Accessors: `centroids()`, `cluster()`, `inertia()`, `n_clusters()`.
- `predict(&self, new_data) -> Result<Vec<usize>, FdarError>`: z-norm each new
  series, SBD to each stored centroid, argmin. Stored centroids used as-is.

### T3 — Shape extraction (decision 5 — the crux)
- `shape_extraction(members_aligned rows, m) -> Vec<f64>`:
  - Stack shift-aligned z-normed members into X (n_k×m).
  - S = XᵀX (m×m); Q = I_m − O_m/m (m = series length); M = QᵀSQ.
  - Top eigenvector via `SymmetricEigen` (ascending → argmax eigenvalue).
  - Sign fix: pick ±v minimizing Σ SBD(±v, member).
  - z-normalize result.

### T4 — kshape_fd core (KSH-03)
- Validation: n_clusters≥1, ≤n, n_init≥1, non-empty → FdarError.
- Up-front z-normalize all series once.
- n_init restarts, seeded `seed.wrapping_add(restart)`, keep min-inertia.
- Per restart: random-partition init (ensure non-empty); iterate to max_iter:
  (a) assign each series to min-SBD centroid, store SBD shift;
  (b) refine each centroid via shape extraction (empty → farthest-point recovery);
  (c) converge on stable labels or |Δinertia| < tol.
- inertia = Σ SBD(series, assigned centroid).
