# Phase 61 — Plan 61-01: SBD Distance Core

**Status:** in-progress

**Scope:** New `src/metric/sbd.rs` — SBD distance primitive + n×n distance matrix. Additive, no new dependency, no version bump (stays 0.33.0).

## Tasks

### T1 — `SbdResult` type (KSH-01)
`pub struct SbdResult { pub distance: f64, pub shift: isize }`, derives `Debug, Clone, PartialEq`, serde-gated, `#[non_exhaustive]`.

### T2 — `sbd(x, y)` core (KSH-01)
`pub fn sbd(x: &[f64], y: &[f64]) -> Result<SbdResult, FdarError>` `#[must_use]`.
- Validate non-empty (`InvalidDimension`).
- Z-normalize both via `shapelet::z_normalize_window` (never trust caller).
- Constant-series guard: if `‖x_z‖·‖y_z‖ ≈ 0` → `SbdResult { distance: 1.0, shift: 0 }`, no NaN.
- `fft_len = next_power_of_two(2*max(x.len(),y.len()) − 1)`. Build ONE `FftPlanner` per call, forward plan reused for both, one inverse plan.
- Zero-pad x_z, y_z to fft_len; `CC = Re(IFFT(FFT(x_z)·conj(FFT(y_z))))`; divide IFFT output by `fft_len` (rustfft unnormalized).
- `NCCc = CC / (‖x_z‖·‖y_z‖)`; scan the `2m−1` meaningful lags (indices `0..m` = shift `0..m-1`, indices `fft_len-(m-1)..fft_len` = shift `-(m-1)..-1`).
- `distance = 1 − max NCCc` ∈ [0,2]; return SIGNED lag as `shift`.

### T3 — `sbd_distance_matrix(data)` (KSH-02)
`pub fn sbd_distance_matrix(data: &FdMatrix) -> Result<FdMatrix, FdarError>` `#[must_use]`.
- n×n symmetric, zero diagonal, `D[i][j] = sbd(row_i,row_j).distance`.
- Upper triangle via `iter_maybe_parallel!` outer loop (each task builds its own `FftPlanner` — `sbd` does this internally); `row_to_buf` each row; mirror to lower. Seq/parallel bit-identical.

### T4 — Wiring
`metric/mod.rs`: `pub mod sbd;` + `pub use sbd::{sbd, sbd_distance_matrix, SbdResult};`. No crate-root flat re-exports (Phase 63).

### T5 — Tests (inline)
self_zero, symmetric, shifted_copy (signed lag), offset_scale_invariant, ncc_bounds, constant_series, matrix_symmetric_zero_diag, matrix_parallel_matches. Doctest on `sbd`.

## Seam for Phases 62/63
`sbd` returns `(distance, shift)` where `shift` is the signed cyclic lag by which `y` aligns to `x`. Phase 62 stores `shift` for centroid shift-alignment; Phase 63 feeds `sbd_distance_matrix` to `kmedoids_from_distances`.
