## Documented divergences (acceptable)

- SBD uses linear zero-padded cross-correlation → a zero-filled shifted copy is not bit-exactly 0 (test gates on signed-shift exactness + distance < 0.05). Inherent to the Paparrizos SBD definition.
- Empty-cluster recovery is in-place farthest-point (mirrors `kernel_kmeans.rs`); documented divergence from tslearn's full-restart.
- `n_init` default 10 (fdars convention) vs tslearn's 1.
- rustfft IFFT unnormalized → explicit `/fft_len`; NCC coefficient-normalized; shape-extraction centering `Q = I_m − O_m/m` (time-dim m).
