# Requirements: fdars — v0.37.0 WAV (Wavelet-Domain Functional Regression)

**Defined:** 2026-09-04
**Core Value:** A comprehensive, fast Rust functional-data-analysis library that closes the highest-leverage capability and performance gaps against reference ecosystems — this milestone promotes **GAP-07** (wavelet-domain functional regression, `wcr`/`wnet`), rank 6 in the v0.31.0 `GAP-BACKLOG.md`.

**Reference baseline:** refund@0.1-38 (`wcr`, `wnet`). Standard orthogonal DWT (Haar + Daubechies) construction. Numeric-output parity is the goal — NOT implementation/basis-internal parity with refund's exact wavelet package internals (documented divergences acceptable, see Out of Scope).

## v1 Requirements (this milestone)

Requirements for v0.37.0. Each maps to exactly one roadmap phase. Strict dependency chain: DWT primitive → wavelet-domain regressors (`wcr`, `wnet`) → prediction + integration.

### Wavelet Transform (DWT)

- [x] **WAV-01**: Forward/inverse orthogonal DWT — Haar (db1) + Daubechies (db2–dbN) filter families, multi-level decomposition, with perfect reconstruction (forward→inverse round-trip recovers the input within numerical tolerance). New DWT module (crate has `rustfft` but no discrete wavelet transform).
- [x] **WAV-02**: Boundary handling — selectable periodic and symmetric boundary extension modes; correctly handles arbitrary (non-power-of-2) signal lengths without panicking (descriptive `FdarError` on invalid inputs).

### Wavelet-Domain Regression (Gaussian response)

- [x] **WAV-03**: `wcr` — wavelet-domain PCR/PLS scalar-on-function regression: transform each curve to wavelet coefficients, then fit via PCR (and PLS) in the wavelet-coefficient space; returns a result struct with the coefficient function β(t), intercept, and fitted values. Reuses fdars' existing FPCR/PLS patterns (`scalar_on_function/`).
- [x] **WAV-04**: `wnet` — wavelet-domain elastic-net regression: lasso + ridge penalty on the wavelet coefficients via coordinate descent + soft-thresholding (reusing `scalar_on_function/additive.rs` GroupLasso machinery), with sparse coefficient recovery and cross-validated λ selection; returns a result struct with β(t), intercept, fitted values, and selected coefficients.

### Prediction & Integration

- [x] **WAV-05**: Out-of-sample prediction + diagnostics — `predict` on new curves for both `wcr` and `wnet` fitted results (self-consistent: re-passing training curves reproduces training fitted values within tolerance); coefficient-function + fitted-value accessors; standard result-struct outputs.
- [x] **WAV-06**: Integration — crate-root + prelude re-exports of the full public surface (DWT + `wcr` + `wnet` + config/result types + predict); a running end-to-end module doctest under `cargo test --doc`; additive/non-breaking (no changes to existing public signatures — R + WASM bindings + 28 examples unaffected).

## Future Requirements (deferred)

Acknowledged but out of this milestone's scope. Tracked for future promotion.

### Wavelet regression breadth

- **WAV-F1**: Binomial / logistic (and other GLM families) wavelet-domain regression — refund's `family` argument. Deferred: this milestone is Gaussian-only.
- **WAV-F2**: Additional wavelet families (Symlets, Coiflets, biorthogonal / CDF wavelets) and wavelet-packet decomposition beyond the Daubechies family.
- **WAV-F3**: 2D / surface DWT and wavelet regression on functional surfaces.

## Out of Scope

Explicitly excluded this milestone. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Non-Gaussian response families (binomial/logistic/Poisson) | Gaussian-only scope decision; deferred to WAV-F1. Keeps the numerical-gate surface bounded. |
| Symlets / Coiflets / biorthogonal wavelet families, wavelet packets | Daubechies (incl. Haar) covers the refund `wcr`/`wnet` parity target; other families deferred to WAV-F2. |
| Exact basis-internal parity with refund's `wavethresh`/`wmtsa` internals | Numeric-output parity is the goal, not implementation parity; documented divergences acceptable (same convention as prior milestones). |
| 2D / surface wavelet transforms & regression | 1D functional predictors only this milestone; deferred to WAV-F3. |
| New crate dependency (e.g. an external wavelet crate) | Reuse-first / no-new-dependency convention; the DWT is implemented in-crate. |
| Continuous wavelet transform (CWT) as a general primitive | A Morlet CWT already exists for seasonal strength (`seasonal/strength.rs`); this milestone adds the *discrete* orthogonal transform for regression, not a general CWT. |
