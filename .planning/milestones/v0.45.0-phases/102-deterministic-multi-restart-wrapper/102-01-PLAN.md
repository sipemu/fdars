<objective>
Wrap Phase 101's single-init L-BFGS soft-DTW barycenter refiner in a deterministic
multi-restart driver (SDTW-02): run the local optimizer from the unperturbed pointwise mean
(restart 0) plus deterministically-seeded Gaussian-perturbed inits, and return the barycenter
with the lowest total soft-DTW cost, reproducibly for a fixed seed.

Purpose: The soft-DTW barycenter objective is non-convex; a single init from the pointwise mean
can stall in a local minimum. Multi-restart escapes those by keeping the lowest-cost run. This
phase builds the internal capability; the public config API (n_restarts/seed) is Phase 103 and
the escape-from-local-minimum quality evidence is Phase 104.

Output: Private helpers in `fdars-core/src/metric/soft_dtw.rs` — a reusable single-init refiner
extracted from the existing descent, a multi-restart driver, a seeded-perturbation helper — plus
SDTW-02 unit tests. Strictly additive and non-breaking: the public 4-arg
`soft_dtw_barycenter(data, gamma, max_iter, tol)` signature and the `SoftDtwBarycenterResult`
struct shape stay byte-compatible, no new crate dependency, wasm32-safe.
</objective>

    Move the descent verbatim: it takes an owned `init` as the starting `bary`, keeps all Phase 101
    safeguards (curvature guard s^Ty > 1e-20, non-descent fallback d=-g + history clear, Armijo

    byte-compatible behavior: keep the n==0/m==0 early return and the non-finite/<=0 gamma
    pointwise-mean fallback exactly as-is, then delegate the descent to
    `lbfgs_refine_from_init(&rows, init_barycenter_mean(&rows), gamma, max_iter, tol)`. This is the
    key_link: one descent implementation, two callers. Because restart 0 of the multi-restart driver
    is also the unperturbed mean, the 4-arg path and multi-restart restart-0 run identical descents.

    Add a private per-evaluation-point std helper `fn per_col_std(rows: &[Vec<f64>], m: usize) -> Vec<f64>`:
    for each column j (0..m) compute the population std of {rows[i][j]} across the n rows (mean then
    sqrt of mean squared deviation). Guard the n==1 / zero-spread case so a column with no spread
    yields std 0.0 (that coordinate is then unperturbed — acceptable, restart 0 already covers the
    mean).

    Add a private seeded-perturbation helper `fn perturbed_init(mean: &[f64], col_std: &[f64], seed: u64, k: u64) -> Vec<f64>`:
    build `StdRng::seed_from_u64(seed + k)` (project convention), a `Normal::new(0.0, 1.0)` standard
    normal, and return `mean[j] + col_std[j] * rng.sample(normal)` per coordinate. Draw noise in a
    single left-to-right pass over j so the RNG consumption order is fixed (determinism depends on it).

    Add the private multi-restart driver
    `fn soft_dtw_barycenter_multirestart(data: &FdMatrix, gamma: f64, max_iter: usize, tol: f64, n_restarts: usize, seed: u64) -> SoftDtwBarycenterResult`:
      - Reproduce the same n==0/m==0 and non-finite/<=0 gamma guards as the 4-arg entry (return the
        same fallbacks) so the driver is safe standalone.
      - Compute `rows`, `mean = init_barycenter_mean(&rows)`, `col_std = per_col_std(&rows, m)`.
      - Treat `n_restarts.max(1)` restarts. Restart 0 uses `mean.clone()` unperturbed. Restart k>=1
        uses `perturbed_init(&mean, &col_std, seed, k as u64)`.
      - For each restart run `lbfgs_refine_from_init(&rows, init, gamma, max_iter, tol)`, then compute
        its TOTAL cost `total = rows.iter().map(|r| soft_dtw_distance(&result.barycenter, r, gamma)).sum::<f64>()`.
      - Winner = strictly-lower total cost; on a tie keep the earlier restart index (iterate ascending
        and only replace the best when `total < best_total`, never on `==`) — this is the determinism
        tiebreak. Return the winning restart's `SoftDtwBarycenterResult` unchanged.

    Keep everything private (no `pub`) — n_restarts/seed are NOT exposed here (Phase 103). Use the
    crate RNG import idiom (`use rand::prelude::*; use rand_distr::Normal;`) local to the module or
    function per existing crate style; add no new Cargo dependency. All new code must be free of
    `linalg`/`argmin` gating so it compiles on wasm32.
