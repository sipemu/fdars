<objective>
Consolidate four `_1d`/`_2d` function families onto single `Dim`-dispatched public signatures and rename the `LpeerResult` result type to `LocalPeerResult`, for `fdars-core` v0.42.0. This is a pure API-shape change: no numeric or behavioral change. Every consolidated public signature dispatches on `Dim` and delegates to **byte-identical** private `_impl` bodies moved verbatim from the current `_1d`/`_2d` functions.

Purpose: Resolve the small, low-blast-radius naming inconsistencies before Phase 88 (the large suffix batch). The removed lone `_1d`/`_2d` public forms and the `LpeerResult` type rename are intentional, pre-authorized breaking changes for the v0.42.0 breaking milestone.

Output: New public names `geometric_median`, `hausdorff_self`, `hausdorff_cross`, `functional_spatial`, `kernel_functional_spatial` (all `Dim`-dispatched) and type `LocalPeerResult`; removed names `geometric_median_1d/_2d`, `hausdorff_self_1d/_2d`, `hausdorff_cross_1d/_2d`, `functional_spatial_1d/_2d`, `kernel_functional_spatial_1d/_2d`, `LpeerResult`; new private `_impl` fns carrying the verbatim bodies. `hausdorff_3d` is unchanged.
</objective>
