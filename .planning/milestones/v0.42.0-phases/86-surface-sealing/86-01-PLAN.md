<objective>
Seal the `wire` interchange module `pub(crate)` and mark every not-yet-sealed public config struct `#[non_exhaustive]`, giving each a documented `..Default::default()` construction path. This is a mechanical, API-shape-only refactor of `fdars-core` — no numeric or behavioral change, no new dependency.

Purpose: Future-proof the public config surface against post-1.0 field additions (v0.42.0 is a deliberate breaking milestone) and remove the unsupported `wire` interchange surface until JS/R bindings need it.
Output: `wire` sealed `pub(crate)`; 38 config structs marked `#[non_exhaustive]`; crate + 28 examples + doctests still compile.

## Artifacts this phase produces
This phase produces NO new public symbols. It REMOVES `wire` from the public surface (`pub mod wire` → `pub(crate) mod wire`) and ADDS `#[non_exhaustive]` attributes to 38 existing public config structs. No new `Default` impls are created — the research verified all 38 already have `Default`. The only "new" text is the `#[non_exhaustive]` attribute lines and lightweight `..Default::default()` doc examples.
</objective>
