## Notes

- **Leverage formula:** `leverage_score = fdars_ns × max(1.0, fdars_ns / min_other_ns)` where `min_other_ns` = min of python / r_svd mean_ns for the same op/size cell. When fdars is fastest: leverage = absolute time only (factor = 1.0).
- **`r_native_pca_fd` excluded from ranking:** The `r_native_pca_fd` library rows (fda::pca.fd, B-spline coefficient space) are ecosystem-realistic R timings and are NOT used in the ranking denominator or as ranked targets.
- **FPCA quadrature disclosure:** fdars/R use Simpson's-weighted SVD; scikit-fda uses trapezoidal quadrature. fdars-vs-R subspace cosine = 1.0000 every cell (validated). fdars-vs-python dips to 0.9816 @ n=500,m=50 (trailing PC divergence). FPCA rows carry the disclosed cosine in the `notes` column of comparison.csv.
- **FPCR cross-library divergence disclosure:** scikit-fda FPCA→OLS vs R fda.usc `fregre.pc` use related but not identical FPCR implementations. Cross-library correlation ~0.95→0.86 as n grows. Recorded per cell; not hard-gated.
- **Karcher-mean elastic excluded:** All Karcher-mean elastic cells failed the noise gate (RSD 29–46%). The elastic anchor is confirmed by the noise-stable pairwise `elastic_align_pair` and banded cross-alignment cells (N≥100).
